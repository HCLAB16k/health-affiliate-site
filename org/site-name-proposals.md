# サイト名の新案（5案）

- 作成: 経営企画 / 2026-09-28
- 依頼: オーナー（「カタカナのジェントルマンズケアがしっくりこない」）。**決定はオーナー。**
- 採用後の作業（AI側）: title・ヘッダーのロゴ・フッター・about.html・disclosure.html・各記事の表記の一括置換、D0008 として記録。

## 前提にしたこと（これまでの案件で確認した内容）

1. **読者**: 30代以上のビジネスパーソン男性。押しつけがましくない、落ち着いた語り口を好む層（PLAN.md 1章）。
2. **当社の強み**: ランキングではなく、一次情報（学会ガイドライン・厚労省・海外の公的機関）で「判断の材料」を示す中立ガイド（0001・0003・0004 のレビューで一貫して評価された点）。
3. **テーマの広がり**: 肌・髪・体・睡眠に加え、海外との比較（ビタミンD、レチノイド等）、季節記事。特定の悩みに寄せた名前だと、今後のテーマが入りにくい。
4. **法規制上、名前に入れない方がよい語**:
   - 効果を連想させる語（「効く」「若返り」「アンチエイジング」「育毛」「薬」等）→ サイト名自体が効能表示のように読まれるおそれ。
   - 専門家の関与を装う語（「ドクター」「医師監修」「研究所」「ラボ」「クリニック」等）→ 医師・研究機関の関与が無いため、優良誤認や信頼性の問題（E-E-A-T）。
   - 最大級表現（「No.1」「最強」「完全」等）。
5. **カタカナの長い語を避ける**（オーナーの違和感の中心と推測）。漢字・ひらがな中心で、口に出しやすく、検索でも覚えやすい長さ。

### 経営企画の推し

**1「男の養生帖」**。理由: ①カタカナを避けたいという意向に最も合う ②「養生」は効能ではなく日々の手入れを指し、薬機法上の懸念が小さい ③肌・髪・睡眠・栄養・季節記事のどれにも合い、テーマが広がっても変える必要がない ④「帖」で「記録・手引き」の性格が出て、中立ガイドの立ち位置と合う。
渋さが気になる場合は、サブタイトル「30代からの、根拠で選ぶセルフケア」で若さを補う。

次点は **3「たしかめる身だしなみ」**（編集方針が最も伝わる）。

## 決める前にオーナーに確認してほしいこと

- **独自ドメイン**を取る予定があるか（取る場合、ローマ字表記の候補も合わせて考えます。例: yojocho / tashikameru など）。
- **商標**: 特許庁の J-PlatPat（https://www.j-platpat.inpit.go.jp/）で同名・類似の登録が無いかの確認（AI側でも調べられますが、最終確認はオーナーが推奨）。
- **SNSアカウント名**の空き（X 等を使う場合）。

## サブタイトル案（どの名前とも組み合わせ可）

- 30代からの、根拠で選ぶセルフケア
- 選ぶ前に、確かめる。大人の男の身だしなみと健康の手引き
