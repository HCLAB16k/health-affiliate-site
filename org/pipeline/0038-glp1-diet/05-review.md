## 持ち越し論点の最終判断
（04「前工程への質問・異議」の5点）

1. **タイトルの「勧められない」（04 異議2）**: **案1のままでよい。ただし条件つき（#3）。**
   - 強すぎるとは判断しない。記事の「GLP-1ダイエット」は委員会資料の定義どおり「適応外で美容・痩身・ダイエット目的で使用すること」に限っている（要点1、l.73）。この使い方について、資料はもっと強い語で書いている。ガイドラインは医療機関に「投与してはならない」、日本肥満学会は「用いる薬剤ではない」、厚労省通知は「安全性及び有効性は確認されておらず…十分な注意が必要」。「勧められない」はこれらより弱く、「禁止」とも書いていない。05-style-rules ⑦（見出しが本文より強くならない）にも反しない。
   - 足りないのは帰属。title は問い（なぜ勧められない？）だが、本文に「勧められない」とまとめた主体と理由を答える文がない。リード（l.59）も `#views` の冒頭（l.134）も、機関の記述を並べるだけ。読者からは、当社の結論なのか機関の結論なのか見分けにくい。style-guide 4章（当社の整理には目印）と 3章（見出しの直後の文で答える）に合わせて、当社の整理だと分かる1文を足すことを公開の条件にする（#3）。
   - 案2に替える必要はない。#3 の1文が入らない場合だけ案2に替える。
2. **FDA の移動先 URL（04 異議1）**: **移動先の URL を［19］に使うことを承認する。** 旧 URL は HTTP 301、新 URL は 200。WebFetch で開くと、本文で使った記述はすべて一致した（下の出典照合）。301 の Location にはクエリ（`?2485ce93_page=4…`）が付くが、記事の URL はクエリのない正規の形で、これで正しい。写しの台帳（`.sources/README.md` l.527）と 01 は旧 URL のまま（#8）。
3. **keywords.csv（04 異議3）**: **販売名 KW を足さない判断を支持する**（00 ②）。カテゴリ列の「ボディ」か「栄養」かは分析部の判断でよく、審査上の問題はない。
4. **2型糖尿病の薬の販売名（04 異議4、00 ②⑥）**: **l.83・84 の書き方を認める。**
   - オゼンピック・マンジャロは日本肥満学会［2, p.1］にある名前で、リベルサスは企業文書［3, p.2］の一覧にある名前。どちらの出典も原文で確認した。
   - いずれも「効能が2型糖尿病だけの別の製剤」と区別するための記載で、否定的な文脈にある。リンク・CTA・入手方法もない。医薬品等の広告の3要件のうち誘引性を欠くので、広告には当たらない（checklist 4章、手引き R8 PDF p.266）。
   - 企業文書であることは本文（l.84「製造販売企業2社が連名で出し」）と参考資料［3］の両方に書かれている。
   - 肥満症の薬の販売名（ウゴービ・ゼップバウンド）の扱いは #6。重複を減らすことを推奨するが、必須ではない。
5. **国民生活センター 2026 の事例（04 異議5）**: 次のとおり判断する。
   - **件数・受付時期・内容（処方され、意図せず定期購入）・金額を書かないことは認める。** いずれも原文（`gl_kokusen_n-20260623_1.txt`）で確認した。
   - 原文の同じ事例には、「注射したところ、体調が悪くなり私の体には合わなかった」という相談者の申告もある。記事はこれを省いている。checklist 6章（公表された相談事例は内容を変えずに書く／安心側だけを抜き出さない）に照らすと、添えるのが望ましい（推奨 #5）。
   - 事例を契約トラブルの例として使っている箇所なので、必須にはしない。

30代の会社員として「SNS で見た GLP-1 ダイエット、自分も使えるの？」と読んだ。答えは、要点2（BMI と持病の条件がある）と `#visit`（健診で指摘されたらかかりつけ医・内科へ）で、読者が自分で判断できる形になっている。
