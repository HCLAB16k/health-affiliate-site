## 持ち越し論点の最終判断

**A. 1社の時点で条件別の◯を付けてよいか（02 と記事の食い違い、異議1）**
受け入れる。各◯のセルに判定の事実（回数券・営業時間・料金に含まれるもの・60分の月額・120分の内容）が並び、当てはまらない条件（②⑦）も同じ表で「当てはまらない」と書いているため、優良誤認（実際より著しく優れていると示す表示）には当たらないと判断する。⑥（月3〜4万円）は同じセルに入会金・体験料・「最低利用期間は記載なし」があり、要点（71 行）にも留保が入った（C9）。東京都の報告が有利誤認の可能性を指摘したのは「月々○○円～」「初月無料」型の表示で、記事の⑥は「〜円から」型ではなく、2つの金額を並べている。経営判断ログに「1社の時点から印を付ける」を記録すること（必須ではない）。

**B. strength-training-guide の meta description 末尾「商品・ジムの紹介なし。」（04 異議5②）**
第1版では残してよい。本文にジム名・商品名はなく、事実として正しい（04b S10）。比較ページに MMM のリンクを置く時点（第2版）で「商品・ジムの紹介なし（ジムの比較ページへの内部リンクあり）」などに直す（申し送り V2-3）。

**C. fit カテゴリの lead（04 異議5④）**
第1版では推奨の扱い（指摘 #7）。lead は「公的資料で整理した記事です」で、広告の提携先を載せたページが同じカテゴリの一覧に入る。誤認は小さいが、比較ページの性格と合わない。

**D. A8 の掲載条件（比較掲載の可否が未確認）を残存リスクとしてどう扱うか**
- **第1版（リンクなし）では公開を止める理由にしない。** 成果の発生する導線がなく、記事は MMM の公式の表示を出典つきで写しているだけで、A8 のプログラム詳細（書き起こし）に比較掲載を禁じる記載はない。法令上のリスクではなく、**広告主の異議 → 提携解除という事業上のリスク**と位置づける。
- 条件: ①J1（G1 の 1〜8、とくに 6）を、公開と同じ週のうちにオーナーから送る（異議2） ②広告主・A8 から異議があったら、その日のうちに MMM の列・枠・条件別の列をコメントアウトし、経営判断ログに記録する（ページは確認リストの部分だけで残せる構成になっている） ③A8 の管理画面のプログラム詳細に、書き起こしにない「掲載禁止の表現・比較サイト不可」等の項目がないかを、オーナーが J2 のついでに確認する。

### 読者目線の講評
30代以上の会社員として読むと、「どのジムを選べばいいか」には、まだ答えていない。載っているのは六本木店1店だけで、六本木に通えない読者には選択肢がない。ここは隠さず書かれている（要点・表・枠）ので、押し売り感はない。一方で、「契約前に何を見ればいいか」には競合のランキング型の記事よりはっきり答えている。国民生活センターの確認点を比較表の行に対応させた表、総額の出し方、3か月の支払いの例、「公式に記載なし」をそのまま比べる項目にした点、体験の前に聞く質問8つは、ほかの比較サイトにない。料金表を見て「結局いくら、途中でやめられるのか」という冒頭の疑問には、MMM については「料金は分かるが、やめる条件は公式からは分からない」と正直に答えている。弱いのは、比較表が1列で比較になっていないことと、条件別の◯が1社にしか付かないこと。収益ページとしての力は、Dr.トレーニング・24/7Workout など、多店舗で規約を公開しているジムが2社目・3社目として入るかどうかで決まる。商品企画部の審査待ちの追跡を優先してほしい。
