## 前工程への質問・異議

1. **（経営企画・レビュー部へ／要判断）外用トレチノインの書き方「PMDAの検索」は、実際の確認方法より強く読める。**
   経営判断ログ（01異議1）は「外用トレチノインは、国内で承認された製品は確認できなかった（2026-09-27時点、PMDAの検索）」と決めた。一方、01 の【01未確認1】は「PMDA の一般名検索（POST）は JavaScript 依存で curl では**結果が取れなかった**」としている。「PMDAの検索で確認できなかった」と書くと、検索が正常に動いて0件だったように読める。
   編集部の案: 「**当社が 2026-09-27 に PMDA の公開情報を調べた範囲では、国内で承認された外用のトレチノイン製剤は見つからなかった**（経口のトレチノインは白血病の処方薬として承認されている）」。「未承認」とは書かない点はログどおり。リサーチ部が別の方法（PMDA の同一成分一覧ページ等）で検索結果を取れるなら、その出典に差し替える（【要確認F】）。
2. **（経営企画・レビュー部へ／確認）D（ポーラ）の「承認と結び付いた注記」は、現行品 N を直接指していない。**
   `.sources/pola_wrinkleshot_g0850.txt` を読むと、65行「日本初：シワを改善する医薬部外品として2016年7月に初承認された製品」は 60行「日本初*1のシワ改善薬用化粧品として**2017年に発売**」の注記（＝初代品の話）で、現行品「N」の承認を明示した文ではない。「シワを改善する」の注記（67行）は評価試験の説明で、承認とは結び付いていない（02 のとおり転記不可）。
   現行品 N が「医薬部外品」（57行）で有効成分がニールワン（12・100行）であること、ページが「シワを改善」を効能として扱っていることから、ログの判断（D を掲載）を覆すほどではないと考える。ただし記事の表では「**公式ページの表示：シワを改善する**」とだけ書き、「2016年に承認」「日本初」を D の行に書かない。製品の外箱のQRコードから見られる「WEBパンフレット」（13行、使用方法・全成分・使用上の注意）に効能の表示があるかを確認できれば確実になる（【要確認E】）。レビュー部が不十分と判断した場合は D を表から外し、A・B の2品で出す。
3. **（経営企画・レビュー部へ／要判断）米国の外用トレチノインの承認効能（顔の細かいシワの緩和の補助）をどこまで書くか。**
   03異議4 は「米国で処方薬として承認されている効能と明示すれば紹介可」とした。ただしトレチノイン外用は国内に承認品が確認できず、国内で承認されていない医薬品の効能を一般向けに書くことになる。製品名・購入導線が無いので広告の3要件（誘引・特定・認知）には当たりにくいと考えるが、「迷ったら言わない」側の案も用意する。
   編集部の案: 比較表の「米国の扱い」欄は「**処方薬（Rx only）**」だけにし、効能は h3（トレチノイン）の本文で1回だけ、**ラベル自身の限定（"DOES NOT ELIMINATE WRINKLES, REPAIR SUN-DAMAGED SKIN, REVERSE PHOTOAGING, or RESTORE MORE YOUTHFUL or YOUNGER SKIN"）と必ずセットで**原文と訳を並べる【#4】。レビュー部が不可とした場合は「米国でも処方薬」だけにする。製品名（米国の販売名）は書かない（出典表記は「FDA 承認ラベル（トレチノインクリーム0.02%）」）。
4. **（経営企画・03 へ／報告）03 の内部リンクの位置「化粧品のレチノールの節の終わり（処方薬の節より前）」から、節の順番を変えた。**
   発注条件「処方薬（アダパレン）の節と商品の節の間を離す」を満たすため、**比較表 → 処方薬の節 → 化粧品・医薬部外品の節 → 商品の節**の順にした（化粧品の節を処方薬の節の後ろに移した）。skincare-antiaging へのリンクは化粧品の h3 の終わりに置くので、処方薬の節の「中や近く」には入らない（処方薬の h2 が終わり、化粧品の h2 の導入と化粧品の h3 の本文を挟む）。03 の目的（処方薬の一般名と「買えるもの」の導線を並べない）は保てると考える。
5. **（02 へ／情報提供。差し戻しはしない）B の公式ページには、効能の一覧とは別に「乾燥による小ジワを目立たなくする（効能評価試験済）」の注記がある**（`shinnihon_perfectone_wrinklestretchgel_11086000.txt` 344行）。部外品の効能の一覧（276行）には無い文言なので、表の効能欄には入れない。また B の有効成分は「ビタミンPP」と「プロビタミンB5（D-パントテニルアルコール）」の2つ（275・268行）。表の「有効成分」列には両方を公式表記のまま書く。
6. **（リサーチ部・経営企画へ）Epiduo の OTC 化の原文確認で1行足す場合、日本側の欄にも原文が要る。** アダパレンと過酸化ベンゾイルの配合外用剤の国内の区分（PMDA、一般名）が 01 に無い。取れない場合は、米国の行だけ足し、日本の欄は「本記事では確認していない」とする（【要確認A】）。
