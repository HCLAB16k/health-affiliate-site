# 00 発注書: 週次のトレンド調査（直近2週間）→ 新記事・既存記事の更新の起票

- 案件ID: 0050（初回 2026-10-29。以後は毎週の定期実行で同じ手順）
- 起票理由: オーナー指示「過去2週間のサイトのテーマに関するトレンドを分析し、毎週、記事を作るか更新して、新しい情報が検索に出るようにして」

## 目的
- 当サイトのカテゴリ（スキン・ヘア/AGA・ボディ栄養・睡眠疲労・オーラル・ヒゲ脱毛・運動筋トレ・泌尿器性の悩み）に関する直近2週間の動き（行政・学会の発表、制度の変更、承認、注意喚起、季節の需要、話題の検索語）を見つけ、①既存記事の更新 ②新記事 のどちらかを毎週1件起票する
- KPI: 検索表示・クリック（新しさ・正確さで上位を取る）

## 手順（毎週）
1. 調べる: 厚労省・消費者庁・国民生活センター・PMDA・食品安全委員会・学会の新着、医薬品の承認・スイッチOTC、季節要因、Search Console の上位クエリ（オーナー共有があれば）。WebSearch で直近2週間に限る
2. 当サイトとの関係を判定: 既存記事のどこが古くなるか／新しい記事の芽か。中立ガイドの立場で書けるか、規制（D0013・D0015・D0018）に触れないか
3. 1件を選んで起票（更新なら該当記事の案件、新記事なら新案件）。リサーチ→編集→レビュー→公開の通常の流れ（レビュー PASS 前に公開しない）
4. 調査結果は org/trends/YYYY-MM-DD.md に残す（出典URL・確認日）

## 守ること
- SNS（X・YouTube・知恵袋等）は**話題・悩みの発見に使ってよい**（何が話題か、どんな言葉で検索・質問されているか）。ただし**記事の根拠には絶対にしない**（オーナー確認 2026-10-29）。記事に書く事実は一次情報（公的機関・学会・論文・メーカー公式）で確認できたものだけ。SNS の投稿は記事に引用・転載しない
- 煽り・効能の言い切り・恐怖訴求をしない。トレンドに乗るために中立を崩さない

## 経営企画の回答（2026-10-29、初回レポートの質問へ）
1. テンプレート: `org/trends/2026-10-29.md` の構成（1-1 公的機関／1-2 学会／1-3 季節、2 既存記事への影響、3 新記事の芽、4 推奨）をそのまま書式とする。
2. 「期間内の一次情報」と「季節（期間外の一次情報で裏づけ）」の区別: それでよい。
3. Search Console の上位クエリ: 月曜の KPI 更新でオーナーに依頼する（クエリ・ページの上位10件のスクリーンショット）。トレンド調査はその週の最新の値を使う。
