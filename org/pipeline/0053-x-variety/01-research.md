## 前工程への質問・異議

1. **「同じ型ばかり」の原因の一部は、型ガイド v1 自体にある。** v1 の4章チェックリストの1項目めは「1行目が『疑問』か『意外な事実・違い』になっている」。予約中の 10/30〜11/09 の14件（リンク10件・fact 4件）を点検すると、**14件中13件の1行目が「？」で終わる疑問形**だった（例外は 11/09 のみ）。一方、今回集めた反応の多い健康系の投稿41件で、冒頭40字以内に「？」があるのは**1件だけ**（国民生活センターの見出しの中）。疑問形は悪い型ではないが、v1 の「1行目は疑問か意外な事実」という条件が、実際には「疑問」1択として運用されている。v2 では1行目の条件を「型の一覧から選ぶ」に変え、疑問形の連続に上限を設けることを勧める（申し送り2）。
2. **「〜も。」の締めも新しい単調さになっている。** 10/30 以降のリンク投稿10件のうち6件が「（記事で分かること）も。」で終わる（v1 の基本形3行目）。v1 で「整理しました」をやめた結果、別の決まり文句に置き換わっただけになっている。
3. **「トラフィックの多いツイート」は、表示回数・保存数では選べなかった。** X の投稿ページは取得できず（x.com は直接読めない）、公開ページで見えるのは「いいね・リポスト・返信・引用」の数まで。インプレッションと保存（ブックマーク）の数は公開されていない。本書の41件は Yahoo!リアルタイム検索の公開ページに表示された「いいね」の多い順に、医師・薬剤師・公的機関・報道の健康情報の投稿を当社が選んだもの（方法と偏りは「競合上位ページの分析」の注）。数字は 2026-10-29 時点の表示値で、当日の投稿はまだ増えている途中。**メンズ美容・筋トレ・睡眠の分野で、専門職の反応の多い投稿は少なかった**（上位は小児科・ワクチン・消費者被害の話題に偏る）。
4. **リンクを返信に置く形（スレッド2連）は、勧めない。** 理由は「事実確認済みの情報」A・B のとおり。(a) X の製品責任者が 2026-04 と 2026-07 に「リンクは減点していない」「リンクを返信に置く必要はもうない」と投稿している。(b) 公開されている For You の仕組みでは、フォローしていない人の返信はおすすめから除かれる（`OONRetweetReplyFilter`）。返信に置いた URL は、フォロワー以外にはほぼ届かない。(c) 費用は 1回 $0.200 → $0.215 に上がる（返信にも URL があれば $0.20。X の担当者が「自分の投稿への返信も通常の料金」と回答）。(d) X の開発者ガイドラインは「AI が生成した返信」に X の事前承認を求めている。当社の投稿文は AI が作っており、自分の投稿への返信が対象に入るか読み切れない。API の上では、自分の投稿への返信は今も通る（X の担当者の回答、2026-10-14）。→ 型ガイド v2 では「スレッド2連」を**使わない型**として記録し、代わりに **URL なしの fact 投稿を型の実験場にする**ことを勧める（費用も $0.015 で安い）。
5. **SNS の投稿は型の分析にだけ使った。** 41件の投稿の本文は本書に写していない（1行目の型を当社の言葉で分類しただけ）。リアルタイム検索のページの写しは、作業後に削除した。
6. （範囲外・再掲）0045 の異議1（自動化ラベル・AI 生成コンテンツの事前承認）は、今回の開発者ガイドライン（2026-10-29 取得）でも同じ記述のまま。D0023 3項によりアカウント設定はオーナー確認事項なので、本書では状況の再確認だけにとどめる。

## 次工程への申し送り

### 1. 型ガイド v2 の考え方（提案）

- v1 の「疑問から書き始める」を、**「1行目で何か1つを名指しする」**に広げる。名指しするもの: 読者の疑問／よくある誤解／数字1つ／場面／用語／国の違い／対象者。
- **本文だけで「へえ」となる一点（答え）を渡し切る**。記事で分かることの列挙（「〜も。」）は毎回は付けない（付けるのは3回に1回まで、を目安に）。2026-10 の X の更新（滞在時間・最後まで読まれる投稿）とも向きが合う。
- 機関名は v1 どおり2つまで。ただし「1行目の答えに要る機関だけ」をさらに徹底し、**1つで足りるなら1つ**。
- **リンク告知は公的機関の形（【見出し】・具体的な注意や数字・行動・URL）、fact 投稿は個人の専門職の形（リンクなしで言い切れる一点）**に寄せる、という役割分担を勧める。

### 2. ローテーションの規則（案。経営企画の x_post.py の重複チェックの参考）

- 同じ型（下の A〜L と v1 の型1〜8）を**連続する2投稿で使わない**（リンクと fact をまとめた投稿順で判定）。
- 1行目が「？」で終わる投稿は**直近5件のうち2件まで**。
- 1行目の書き出しの形（「〜？」「〜は、〜？」「【」「「」で始まる」「数字で始まる」）が直近3件で同じにならない。
- 締めの「〜も。」は直近3件のうち1件まで。
- 【見出し】は週2件まで（多用すると公的機関の真似に見え、効き目も薄れる）。
- 同じ記事を根拠にする投稿は、7日以上あける（11/03 fact と 11/06 リンクの nocturia、11/01 リンクと 11/07 fact の blue-light は近い）。

### 4. NG の追加（v1 の3章に足す候補）

- 流行している口調・定型（同じ日に複数の医師が使ったキャラクター口調の型など）に乗らない。

### 6. 測り方（0045 の6章に追加）

- 型ごとの効果を比べるには、当社の投稿の数字が要る。Owned Reads（$0.001/件）で自分の投稿のインプレッション・URL クリック数を取れる（0045 で記録済み）。**型の名前を queue の JSON に `"type": "A"` のように持たせる**と、後で型ごとに集計できる（x_post.py は未知のキーを無視するので、追加しても投稿は止まらない。2026-10-29 に validate のコードで確認）。
