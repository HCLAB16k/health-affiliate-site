## 執筆メモ（フェーズB完了時に記入）
- 構成案から変えた点と理由: 構成は変えていない。meta description の「おすすめ順ではありません」を「並びは順位ではありません」に変えた（打ち消しでも「おすすめ」の語を置かないため）。RETØUCH の用途に付けていた「（製品名の表示のとおり）」を削除（メーカーの表示を確認したのではなく Amazon の商品名の表記のため）。
- head: GA4・フォント・アイコン類は about.html と同じものを入れた（build_site.py はカテゴリバーと seo ブロックしか差し込まないため）。seo:start/end は空。meta description は build が拾うよう seo ブロックの外（6行目）に置いた。
- Amazon リンクは3つ（65・84・120行目）。すべて `rel="sponsored nofollow"`、文言「Amazon で見る」。a8linkmgr なし。
- **効果の語・推奨・価格・宣伝文句を書いていない**: `tools.html` を「効果|効能|口臭|歯肉|予防|ツヤ|おすすめ|推奨|円|レビュー|猫|ランキング|改善|清潔」で Grep → 該当 0件（修正後）。
- **区分を書いたのはコンクールFだけ**: 「医薬部外品」は 103行目（コンクールFの用途）と 133行目（「このページについて」の区分の説明）のみ。
- 販売元の記載: 52行目（基準）、64・83・119行目（各 affiliate-box）、98行目（fluorfloss の見送り理由）、127行目（napla の見送り理由）。出品者名（第三者）は書いていない。
- napla の見送り理由は、ブリーフの「サロン中心の販売経路」が一次の記録に無いため「販売元を確認できていない」とだけ書いた。
- 無印良品の舌ブラシは、owner-experience に記録の公式 URL を広告ではないリンク（`rel="noopener"`）として置いた（72行目）。不要なら削除可。
- 解説記事（oral-care-basics 等）への逆リンクは置いていない（構成案どおり）。ヘッダー・フッターへの導線と sitemap は未対応（経営企画の担当）。
