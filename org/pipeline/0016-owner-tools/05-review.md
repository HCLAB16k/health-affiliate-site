## 持ち越し論点の最終判断
1. **D0013 と口臭ケア記事からのリンク文言**: 可。l.158 の文は評価・効能・推奨の語を持たず、「一覧は別ページ」「そのページには広告があり紹介料が支払われる」という事実の告知にとどまる。D0013 決定2（評価の言葉を付けない内部リンク）と 0013 レビュー l.113 の条件の範囲内。広告があることを先に告げるのは、読者が広告と知らずに移動することを防ぐ点でむしろ望ましい。ただし直前の注記が矛盾したまま（指摘1）。
2. **リンク段落の位置**（直後にコンクールF の効能枠）: 許容。tools.html にコンクールF のリンクは無く、効能枠の冒頭に「運営者の使用の経験とは、結びつけて読まないでください」がある。tools.html 側にコンクールF の効能を持ち込んでいない（0013 レビュー指摘3の条件を満たす）。
3. **NONIO の区分**: 0013 レビュー指摘8（推奨）は「化粧品（メーカー公式）」の記載を提案したが、tools.html は区分を書かず「確認できたものだけ」と明記している。効能を書いていないので区分を書かないことも可。
4. **updated**: oral-care-basics は `site_data.json` で 2026-09-29（同日の既存の更新）、sitemap も 2026-09-29。追加の更新は不要。

### 読者目線の講評
- 30代の会社員として読むと、「この人が実際に何を使っているか」が一覧でき、リンクを置かない理由（販売元が第三者・メーカーが歯科医院販売を案内）まで書いてあるのは珍しく、信頼できる。押し売り感は無い。
- 一方、「で、自分はどれを選べばいいの？」には答えない設計（評価・適合を書かない）。これは D0013 と薬機法上の制約による意図的なもので、選び方は解説記事が担う分業として妥当。ただし tools.html から解説記事へ戻る導線が無いため、「選び方は各解説記事で」と記事名を出さずにカテゴリページ（category/oral.html 等）へ誘導する1行があると迷子にならない（任意。04 が逆リンクを避けた理由＝推奨・効能の記事と広告を結び直さない、は理解できるので、カテゴリページ止まりを提案）。
- 「使用期間や使い方の細かい点は確認できていない」と正直に書いているのは良いが、読者価値を上げるなら、オーナー取材で「3100 に替えた理由」「NONIO と舌ブラシの使う順番」等の事実（効果ではない）を足せる。owner-inbox への取材依頼の候補。

### 組織への提案（チェックリスト・書式の不足）
- checklist 3章に「開示文の整合: 同じページ・リンク元のページで『報酬は受けていない』と書く場合、アフィリエイト紹介料を明示的に除いた書き方にする（販売店＝Amazon 等から紹介料を受ける場合）」を追加。
- checklist 7章に「サイト全体の広告方針を述べる文（『当サイトの記事には〜』）は、現に描画中の affiliate-box と矛盾しないか `cta-btn` を Grep して確認する」を追加。
- Amazon の販売元・出荷元は WebFetch で取得できないことが多い。販売元を条件にする運用では、確認者（オーナー／経営企画）・日付を inbox に残す現在のやり方を書式化（02-products または 00-brief に「販売元の確認記録」欄）。
