## 持ち越し論点の最終判断
1. **「エイジングケア」の注記の要否 → 注記は必須ではない。ただし「アンチエイジング」の語は外す（必須 #1）**。
   - 根拠: 日本化粧品工業連合会「化粧品等の適正広告ガイドライン2020年版（第2刷）」（2020年6月15日、自主基準）E18「エイジングケア」の表現（`.sources/jcia_adguide_2020.txt` PDF p.21〜22、取得日 2026-09-27、URL は `.sources/README.md`）。
     - 定義:「エイジングケアとは、加齢によって変化している現在の肌状態に応じて、化粧品等に認められた効能・効果の範囲内で行う、年齢に応じた化粧品等によるお手入れ（ケア）のことである。」
     - 認められない表現の範囲:「『エイジングケア』を標ぼうしながら若返り、老化防止、シワ・たるみの防止等の化粧品等の効能効果の範囲を逸脱した『エイジングケア』を用いた表現」。具体例 b）老化防止効果に「**アンチエイジングケア**」、a）若返り効果に「こんな方にオススメのエイジングケア……シワ、たるみが目立ち、老けてみられる」、f）「**エイジングケア成分を配合しました**」。
     - 関連法令として医薬品等適正広告基準 第4の3（1）・3（2）が挙げられている。
   - E18 には、※印などで定義の注記を付けることを求める文は無い。求められているのは、「エイジングケア」をこの定義の範囲で使うことと、老化防止・若返り・シワたるみの防止を含意させないこと。したがって注記は**推奨**（初出に1文、#5）にとどめる。
   - 適用範囲について: 同ガイドラインが対象とする広告は「顧客誘引の意図・特定の商品名・一般人が認知できる」の3要件を満たすもの（PDF p.5〜6）。現状の skincare は商品名もリンクも無いので、厳密には3要件を満たしていない。それでも必須にするのは、①この記事が `pr-badge` で広告を含むと表示している、②affiliate-box はコメントを外せば復活する前提で、復活した時点で3要件を満たす、③本案件の目的が disclosure l.46（化粧品は表示が認められている範囲で紹介する）を事実にすることで、「アンチエイジング」はその基準に反する明示例だから。
2. **「〜を意識した製品に配合」型の言い換え → 可（本案件では）。条件付き**。
   - チェックリスト1章の OK 例（「〇〇を意識する方に選ばれています」）と同じ型で、成分そのものに作用があると言っていない。商品名もリンクも無い成分解説としては許容する。
   - 条件（案件0003以降・リンク復活時に適用。チェックリストへの追記を提案）: ①「意識した」対象は生活場面・属性（会食が多い、年齢を重ねた、植物性を選びたい）を基本とし、症状・身体機能（寝つき、疲れ、ストレス、老化）を対象にするときは、その成分の直後や同じ段落に特定商品のCTAを置かない（成分説明と商品リンクがつながると、その商品の効能の暗示になる）。②CTA の商品が機能性表示食品なら、届出番号と届出表示の原文だけを引用する（既に各コメントに記載済みで良い）。③「配合されることが多い」は市場の傾向の主張なので、出典を付けられないなら「配合されることがある」に弱める（#7）。
3. **pr-badge を残すか → 残す**。
   - skincare・fatigue・sleep・hair は現在アフィリエイトリンクが0件だが、①全ページで A8.net のスクリプト（`a8linkmgr`）を読み込んでおり、ページが広告の仕組みと無関係とは言い切れない、②affiliate-box は提携後に復活させる前提で、外してから戻す運用はバッジの付け忘れのリスクになる、③ステマ規制は広告であることを隠すことを問題にするもので、広告の表示が過剰でも違反にはならない。disclosure l.26（リンクを含む記事には表記する）とも矛盾しない。
   - 文言の厳密さを求めるなら「本記事はアフィリエイト広告を含む場合があります」とする選択肢もあるが、既存記事の形式を揃える（CLAUDE.md 5章）ほうを優先し、変更は求めない。
4. **index の meta description「疲労回復など」→ 推奨で修正（#4）**。index は広告リンクを含まず、「疲労回復」はサイトが扱う分野の名前として書かれているので、公開を止める理由にはならない。ただし記事側は title から「疲労回復」を外し、index のカード h3 も「疲労・エナジーマネジメント」になった。サイトの説明だけが「疲労回復」を使っていると、記事と導線の不一致（チェックリスト7章）になる。
5. **0001 第3回審査 #18（一般用医薬品の推奨度引用の扱いを disclosure に明記）→ 本PRでは不要。0003 に持ち越す**。今回の5記事に、学会ガイドラインの推奨度の引用も一般用医薬品の紹介も無い（Grep「推奨度」「ガイドライン」「第1類」で0件を確認）。0003 は hair を GL2017 と整合させる案件で、医薬部外品・一般用医薬品の有効成分の推奨度を引用する見込みが高い。disclosure l.46 の一般用医薬品の文に1句足す対応は、0003 の編集・レビューで行う（0003 のレビュー観点に加えることを経営企画に提案）。

### 読者目線の講評
30代の会社員として読むと、修正前の「効く」「疲労回復戦略」「短時間でもパフォーマンスを落とさない」が消え、成分の説明が落ち着いた。煽られている感じは無くなった。一方で、どの記事も「〜向けの製品に配合されています」が続き、「で、自分はどれを選べばいいのか」への答えは弱くなっている。例えば sleep は「機能性表示食品かどうかを確認する」「届出表示を確認する」という行動に落ちているのが良い一方、fatigue は選び方が「原因を振り返る・価格を見る・カフェインを確認する」だけで、成分ごとの違いが選択に結びつかない。これは本案件のスコープ（表現の是正）の外で、0003 以降のリライトで「食品で言えることの範囲で、何を基準に選ぶか（原材料表示・1日量・価格・届出の有無）」を軸にすると価値が戻る。protein はリンク先が404なので、ボタンを押した読者の信頼を損なう（#6）。
