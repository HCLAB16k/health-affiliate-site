## 前工程への質問・異議

1. **（経営企画宛て）00-brief の「DAILY BASIC+ WPI は販売中」は一部だけ正しい**。公式ストアの商品データ（products.json）にあるのは「DAILY BASIC+ WPI チョコレート 1kg」だけで、0006 のレビューがストアのトップで見た「DAILY BASIC+ WPI ヨーグルト 1kg」は一覧に無い。終売したばかりの DAILY BASIC と同じシリーズなので、**DAILY BASIC+ は候補から外した**（下の「見送り」）。
2. **（経営企画宛て）A8 の FIXIT プログラムが「どの商品の購入を成果にするか」次第で、やることが変わる**。0006 で貼ったリンク（素材001）はストアのトップに飛び、プログラム名は「FIXIT DAILY BASIC ホエイプロテイン」だった。成果がストア全体の購入なら、**新しい提携は不要で、商品説明を差し替えるだけで済む可能性がある**。オーナー依頼の1番目で確認する。
3. **（編集部・レビュー部への申し送り）カゼインの商品は置かない案を推す**。調べた5ブランドの公式ストアに、単品で売っているカゼインプロテインは見つからなかった（マイプロテインのカゼイン商品URLは 404、ミルクプロテインのカテゴリにも単体カゼインは無い）。記事の商品枠は「ホエイの一例」「ソイの一例」の2つにし、カゼインは本文の説明だけにする。
4. **（レビュー部への申し送り）FIXIT の商品ページの画像に効能のような表現がある**。THINK SIMPLE WPC の商品画像に「疲労回復に欠かせない」「たんぱく質の吸収を高めることは筋肉を増やすことにつながります」「1杯あたりたったの78円」（`.sources/fixit_img/think_simple-wpc_9.jpg`・`_10.jpg`・`_11.jpg`）。広告主自身のページの表示だが、**記事には引用しない**。「78円」は今の価格（1kg 4,320円、1食20〜30gなら約86〜130円）と合わず、根拠が確認できない。

## 選定の軸（読者メリット。効能・体型変化・「人気」は理由にしない）

1. **価格の分かりやすさ**: 公式に税込の定価が固定で出ていて、1kgあたり・1食あたりを計算できるか。セール・クーポン前提で価格が大きく動くものは減点。
2. **原材料・成分表示の明確さ**: 原材料名と1食あたりのたんぱく質量が公式で読めるか（テキストが望ましい。画像のみは可だが減点）。
3. **単品で買えるか**: 定期購入でなくても買えるか。定期は回数の縛りが無く、解約方法が明示されているか。
4. **継続販売**: 終売・売り切れの兆候が無いか（同シリーズの売り切れ、在庫切れのバリエーション）。
5. 記事の種類（ホエイ／ソイ）に対応する商品があるか。

### 見送った商品と理由
- **FIXIT DAILY BASIC+ WPI**（7,480円）: 終売した DAILY BASIC と同シリーズで、味が1種（チョコレート）に減っている。継続販売の見通しが弱い。
- **FIXIT FEEL NATURAL WPC / WPI、ACT ON WPC**: 販売中だが、同じ広告主のホエイで価格が分かりやすく安い THINK SIMPLE WPC を優先。FEEL NATURAL（グラスフェッド）は5,980〜7,480円で、ACT ON はプレーンが売り切れ。枠が1つなら不要。
- **カゼイン単体の商品**: 調べた範囲の公式ストアに見当たらない（前工程への質問3）。
- **ULTORA**（A8 スタッフブログ 2021年に掲載）: 看板商品が「ホエイダイエットプロテイン」で、商品名自体が体型変化を連想させる。0006 レビュー推奨#2（体型の打ち出しを和らげる）と逆方向なので対象外。
- **ALPRON**（同ブログに掲載）: 会社サイト（alpron.co.jp）から一般向けの公式通販を確認できず（リンク先は法人向け alpron.bcart.jp）。公式の価格・原材料を確認できないため対象外（オーナーが A8 で見つけた場合のみ再調査）。

## 決定

- **主推奨（商品）**: 記事の3種類の説明に合わせて**種類別に1品ずつ**置く。
  - **ホエイの一例: FIXIT THINK SIMPLE WPC ホエイプロテイン 1kg**
  - **ソイの一例: FIXIT MAKE BALANCE ソイプロテイン プレーン 1kg**
  - 理由（読者メリット）: ①定価が固定で公式に税込表示があり、1kgあたり（4,320円・3,680円）・1食あたり（約86〜130円・約74円）を計算できる ②単品で買え、定期にしても回数縛りが無くマイページで解約できる ③2020〜2021年から継続販売で、同シリーズも販売中 ④ソイは原材料・1食あたりのたんぱく質量が公式表示で読める。加えて同じ広告主なので、**既存の提携のまま差し替えられる可能性が高い**（これは読者メリットではなく実務上の利点）。
  - **弱点（記事で補うこと）**: THINK SIMPLE WPC は1食あたりのたんぱく質量の栄養成分表示を公式で確認できていない（オーナー依頼3）。確認できるまでは、記事の商品説明に数値を書かず「原材料・栄養成分はリンク先で確認」のままにする。
- **代替案（FIXIT の既存プログラムがストア全体でない／使えない場合）**: **ホエイの一例をビーレジェンド WPC GENMATSU** にする。原材料が「乳清たんぱく」だけで、1食あたりのたんぱく質量・内容量がテキストで表示され、315g・600g の小容量もある（0006 レビュー推奨#1 の解消にもなる）。ソイは FIXIT MAKE BALANCE のまま、ASP が別でも併記できる。
- 推奨する選択肢（医療機関の場合）: 該当なし（食品）。
- **社内の提携優先度（記事には出さない）**: ①FIXIT（既存プログラムの範囲確認→必要なら別プログラム申請）②ビーレジェンド ③マイプロテイン ④VALX。報酬はいずれも未確認のため、順位は読者メリットと提携の手間で付けた。
- **比較表に載せる商品**: 記事は商品のランキング・比較表を作らない（本文の比較表は種類の比較のまま）。affiliate-box に「ホエイの一例」「ソイの一例」として最大2品。
- 見送った商品と理由: 上の「見送った商品と理由」。
