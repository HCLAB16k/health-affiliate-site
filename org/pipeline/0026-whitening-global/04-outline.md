## 前工程への質問・異議

1. **（確認）グレーゾーン回答（`wt_mhlw_001477954.txt` PDF p.1 50行）には照会事業で使う製品の販売名が書かれている。** 論点③に従い本文・参考資料とも販売名は出さない（参考資料は文書名と URL のみ）。
2. **（確認）ADA は、クロルヘキシジン洗口液の長期使用による変色を「内因性」の段落に置いている**（`wt_ada_whitening.txt` 59行 "Intrinsic discoloration can also occur with prolonged use of antiseptic mouthrinse (e.g., chlorhexidine rinse)"）。01 は「着色」とだけ書いている。記事は原文どおり「歯の内側の変色」の節に置き、商品名は出さない。oral-care-basics の「歯面の着色」（メーカー FAQ の表現）とは言い方が違うが、両方とも出典の表現どおりで矛盾はしない（変色が起こりうる、という点は同じ）。oral-care-basics へのリンクはこの文の近くに置かず、「表面の着色」の節の末尾に置く（洗口液の商品と結びついて読まれないように）。
3. **（確認）日本歯科審美学会の指針（`wt_jdshinbi_shishin_hp_20200403`）は会員限定・無断転載禁止と明記されているため、本文の出典には使わなかった。** 同じ内容（禁忌・個人差・後戻り）は PMDA 掲載の添付文書と公開ページで足りた。
4. **（確認）国民生活センターの「セルフホワイトニングのみの平均契約購入金額 約7万円」は書かない。** 論点④（費用の相場は書かない）の趣旨から、相場と読まれうる金額を避けた。福岡県の事例の「48回コース15万円」も書かない。
5. **site_data.json のキー名**: 発注文の「published/updated」は既存スキーマでは `date`／`updated`。末尾の案は既存スキーマのキー名で書いた。
6. **build_site.py は `git ls-files` で HTML を拾う**ため、新記事は `git add` してから build しないとカテゴリバー・seo ブロック・sitemap に反映されない。記事には build の出力と同じ形の cat-nav・seo ブロックを手で入れてあるが、経営企画の build 時に再生成される。

## 独自性（競合にない価値）
- **EU・英国・米国・日本の制度を原文で並べた比較表**（#compare）。01 の競合分析で、この形のページは見当たらなかった。
