## 目的
- 告知の投稿を「記事の要約（〜を整理しました）」から、読者が止まって読み、クリックしたくなる形に変える。
- 指標: X からのクリック（GA4 の流入元）、インプレッション、反応。

## スコープ
- 分析の対象: 日本語の健康・美容・男性向けセルフケアの分野で、反応の良い投稿の型。
  - 方法: 公開の記事・分析、公開された投稿の例を Web 検索で調べる。X API の読み取りは使わない（費用がかかるため）。
  - 投稿の本文を大量に転載しない。型の分析にとどめる。
- 成果物:
  - `org/social/x-style-guide.md`（投稿の型・NG・チェックリスト）
  - 予約済みの投稿（10/14 以降の未投稿分）の書き直し案
- やらないこと（checklist 3章・4章を守る）:
  - 煽り、断定、最大級、効能の言い切り、恐怖訴求、体験談の捏造
  - ステマ（アフィリエイトリンクのある記事の告知は #PR）
  - 薬機法の効能・医療広告の要件の逸脱

## 各部署への注意点
- リサーチ:
  - 確かめる型: 冒頭の一文（問い・意外な事実・数字）、改行、箇条書き、文字数、URL の位置。
  - あわせて調べる: リンク付き投稿の表示の扱い（リンクを本文に入れると届きにくいと言われる点の一次情報の有無）、スレッド、画像。
  - 当社の制約に合わせて評価する: 中立・出典・確認日、URL 付きの投稿は $0.20／件。
- レビュー: 書き直しの文面を、記事と同じ基準で審査する。
