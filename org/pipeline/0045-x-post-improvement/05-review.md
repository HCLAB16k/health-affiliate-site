## 持ち越し論点の最終判断

### 1. 10/14 oral-care-basics の #PR は**外す**
- 根拠は次の3つ。
  - D0010 と checklist 3章の基準は「アフィリエイトリンクが描画される記事への告知には #PR」。oral-care-basics はリンクを描画していない（`article_has_ad_links` が False、pr-badge は「当サイトはアフィリエイト広告を利用しています」）。
  - 09-28 の審査が #PR を残した理由は、A8 の自動置換の ON/OFF が分からないことだった。その審査は「D4 で OFF と確認できたら外してよい」としている。D4 は 2026-09-29 に OFF になった（owner-inbox）。
  - 記事から tools.html（広告あり）への内部リンクはある。ただし評価の言葉を付けない内部リンクで（D0013-2）、記事そのものを広告にするものではない。
- 広告でないページに #PR を付けても、法令違反にはならない。ただ、ほかのリンクなし記事 20 件には付けていない。この1件だけに付けると、#PR が「広告のある告知」の目印として働かなくなる。そのため外す側に揃える。
- 条件: A8 の自動置換を再び ON にするとき、または oral-care-basics にリンクを足すとき（D0013 により今は置けない）は、この判断を見直す（checklist 7章 A8 の項）。

### 2. #PR は**文頭に置く**（可。今後の標準にする）
- 運用基準 第3の1⑵オが不明瞭な例に挙げるのは「視認しにくい表示の末尾の位置」。末尾に置くこと自体が直ちに違反になるわけではない。ただ、今の形は長い URL の後ろに #PR があり、タイムラインではリンクカードの直前に小さく出る。⑵オに近い見え方になる。
- 文頭の「#PR」は、2⑴アの「PR」の文言による表示に当たる。表示の内容とも矛盾しない（⑵イの「冒頭は広告、文中は第三者の感想」型には当たらない。案の本文に第三者を装う文は無い）。
- ハッシュタグは #PR の1つだけなので、⑵ク（大量のハッシュタグに埋もれさせる）にも当たらない。
- **x_post.py は #PR の有無しか確かめない（位置は見ない）**。位置は投稿前のチェックリストで目で確かめる（指摘 S7）。
