## 前工程への質問・異議

1. **自動化ラベル（発注書の範囲外だが重要）**: X の開発者ガイドライン（docs.x.com、2026-10-13 取得）は、API を使う自動化アカウントの要件として「Automated」ラベルを付けること、自己紹介で自動であることと運用者を明示すること、人が管理するアカウントと関連付けることを挙げている。違反時の処分として「app suspension, API access revocation, or permanent account bans」と書いている。当社はオーナー判断（2026-09-29、`org/social/x-account-setup.md`）でラベルを付けず、自己紹介に「自動で」と書く運用にしている。投稿文をどれだけ改善しても、アカウントが止まれば効果はゼロになる。**オーナーに再判断を仰ぐことを勧める**（owner-inbox）。あわせて、同ガイドラインは「AI-Generated Content & Replies」に X の事前承認が要るとしている。予約投稿（当社の文は AI が作成）が対象に入るのか、返信だけの話なのかは原文から読み切れない（未確認）。
2. **10/14 の #PR**: oral-care-basics は、いまアフィリエイトリンクを描画していない（`x_post.py` の `article_has_ad_links` が False。記事の pr-badge も「当サイトはアフィリエイト広告を利用しています」）。発注どおり #PR は残したが、#PR の付け方の基準（D0010: アフィリエイトリンクが描画される記事）とは合っていない。付けておくのは安全側なので害は小さい。残すか外すかはレビュー部の判断に回す。
3. **#PR の位置**: 消費者庁のステマ告示の運用基準は、事業者の表示であることが不明瞭な例として「視認しにくい表示の末尾の位置に表示する場合」（第3の1⑵オ、PDF p.8）と「大量のハッシュタグ…の中に埋もれさせる場合」（同ク）を挙げている。当社の #PR は URL の後ろ（末尾）にある。短い投稿なので見落とされにくいとも言えるが、安全側として書き直し案では**冒頭**に移した。発注書は「#PR の有無は今と同じ」としているため、位置の変更はレビュー部に判断してもらう。
4. **「反応の良い投稿の分析」の限界**: X API の読み取りを使わない条件では、日本語の健康・美容系アカウントの反応の数字を集められない。Web 検索でも、日本語の健康系の投稿の型を数字で比べた公開の分析は見つからなかった（検索語は「要約」に記載）。本書の「型」は、(a) 健康情報のツイートの研究（英語圏2本・日本語1本）、(b) X 自身の公開資料（アルゴリズムのコード・開発者ドキュメント・幹部の投稿）、(c) 二次情報（Buffer・Nieman Lab・国内のマーケティング記事）、(d) 当社の投稿文の点検、の組み合わせで作った推定である。効果は自社の数字で確かめる必要がある（申し送り4）。
5. **反応を増やす要因の一部は当社では使えない**: Lohmann 2018 は「恐怖の言葉」を RT の最も強い予測因子の一つとし、厚労科研の報告は、減塩についての誤情報のほうがエビデンスに基づくツイートより多く RT されたとしている。発注書の「煽らない・断定しない」とは両立しない。当社の型は「問い」と「意外な事実」で止まってもらう方向に限った（反応の伸びは、恐怖訴求を使う発信者ほどにはならない可能性がある）。

## 要約（3行）

- 今の予約投稿（10/14〜11/09 の23件）は、全件が「〜の資料で整理しました」型の要約。1文目が疑問になっているのは4件だけで、機関・資料の名前が3つ以上並ぶものが約10件ある。本文は平均約110字。**答えを見せる前に資料の名前が並ぶ**のが「つまらない」の主な原因と見る。
- 「リンクを本文に入れると届きにくい」は、X の一次情報では**確認できない**。製品責任者は「リンクは減点していない。反応が低いので直そうとしている」（2025-10-19）と投稿し、公開コードの重みにも URL 自体の減点項目は見当たらない。届きにくいというデータは二次情報（Buffer 2025・Nieman Lab 2026）のみ。返信に URL を置く形は費用が増え（URL 付きの返信も $0.20）、スクリプトの改修も要るので、当面は勧めない。
- 当社の制約内で使える型を8つにまとめ（`org/social/x-style-guide.md`）、23件の書き直し案を作った。全件 `x_post.py` の検証を通る（重み付き 194〜279）。1行目を読者の疑問か意外な事実にし、事実は1〜2個、機関名は原則2つまで、URL は最後の行に置いた。

（日本語の健康系の型を数字で比べた分析を探した検索語: 「医師 薬剤師 X 発信 伸びるポスト 書き方」「X 投稿 インプレッション 伸びる 型 分析 1行目 数字 問いかけ」「美容 健康 アカウント X 伸びる 有益ポスト 型」「自治体 公式X 健康 投稿 工夫 反応」「皮膚科医 ポスト 話題 万いいね」「薬剤師 ポスト 反響 X 万いいね」。いずれも数字のある比較は見つからなかった）
