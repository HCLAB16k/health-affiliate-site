## 1. 共通で変えたこと

- 冒頭の「この記事について」を削り、まとめの後・関連記事の前に `<h2 id="method">この記事の作り方</h2>` を新設（［n］→確認日→資料の範囲→利益相反→記事の範囲→商品・リンクの扱い。1項目1文）。
- 冒頭に残した必須の文（線引き④）:
  - oral: 運営者の使用品を商品名つきで載せている記事なので、リードと別の1行に「記事の後半に、運営者が使っている道具を商品名つきで載せています（アフィリエイトリンクなし）。」（l.61。skincare l.61 と同じ形）

- リードを1段落に（読者の場面 → この記事で分かること）。oral 約150字、whitening 約140字。
- 「先に結論」「先に要点」の `<p><strong>` を `<h2 id="summary-top">先に要点</h2>` にした（winter-vitamin-d と同じ型）。要点は2記事とも5項目。全項目に［n］を付けた（⑦）。
- h2 を読者の疑問の形にし、直下の1文で答えた。h3 は資料名・論点名のまま（whitening の FAQ の h3 2つだけ直した。下の4章）。
- 出典番号を［1, 2］の形にそろえた。表のセルの［n］［n］は、表には手を入れない方針でそのまま。
- 「」の原文は言い換えていない。並ぶものは箇条にした（NHS の4点、ADA の3分類、通知の理由と結論、照会の事業、学会のサロンの見方、相談事例、特商法で適用されないルール、舌の清掃の時間帯、医療機器の表示、効能の範囲）。
- **既存の id はすべて残した**（Grep で新旧を比較）。他記事からのアンカーは oral の `#pillars #differences #overdo #visit #ads`（mens-selfcare-start）で、すべてある。whitening へのアンカーは他記事に無い。追加した id は2記事とも `summary-top`・`method` だけ。
