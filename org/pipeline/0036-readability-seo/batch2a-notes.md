## 1. 共通で変えたこと

- 冒頭の「この記事について」「この記事の掲載基準」を削り、まとめの後・関連記事の前に `<h2 id="method">この記事の作り方</h2>` を新設した（順番はガイド6章: ［n］と確認日 → 使った資料・範囲 → 商品・医療機関の扱い）。**2記事ともリンク・商品名・運営者の使用品が無いので、冒頭に残す必須の文（線引き④）は無い**（caffeine の OK 例と同じ扱い）。pr-badge は l.55 のまま。
- リードを1段落にした（読者の場面 → この記事で分かること）。
- h2 を読者の疑問の形にし、直下の1文で答えた。効能の問い（「〜で減る？」「〜で生える？」）・恐怖の問いは使っていない。
