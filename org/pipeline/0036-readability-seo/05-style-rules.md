## 全体の原則（7項目に共通）

1. **言い換えてよいのは「形」まで。** 主体（誰が言ったか）・対象（誰についてか）・条件（量・時刻・期間）・留保（可能性がある、個人差、推定、「といわれています」）・数値・出典は、短くしても全部残す。
2. **当社の地の文が、効能・安全・推奨を言わないこと。** 伝聞を外した結果、効能や安全性の記述が当社の断定になったら NG。迷ったら伝聞に戻す（checklist 冒頭「言わない側に倒す」）。
3. **原文の引用（「」の中）は言い換えない。** 機能性表示食品の届出表示、医薬部外品の承認効能、ガイドラインの推奨文、行政の回答は、短くするなら抜粋にし、抜粋でも留保・対象の部分を落とさない（checklist 1章・6章 0026）。
4. **短くした結果、要点・見出し・表・meta description が本文より強くならないこと。** 本文の条件が要点に1つでも欠けたら差し戻す。
5. **構造化データ（JSON-LD）・HTMLコメント・画像の alt も本文と同じ基準。** FAQ を構造化データに入れるなら、画面の文と同じ帰属・留保を付ける（checklist 7章「HTMLコメントも公開物」と同じ考え方）。

## ① 伝聞の形（「〜は…としています」）

### 変えてよいもの
- **帰属を文頭へ移す。** 「A は、…、としています」→「A によると、…」「A の目安は…です」。読者は文頭で誰の話かが分かる。
- **同じ機関が続くときは、2文目から主語を省いてよい。** 条件は、(a) 同じ段落の中、(b) 間に別の機関や当社の意見が入らない、(c) 2文目以降も原文の留保（「〜ことがある」「可能性がある」）を保つ、の3つ。
- **前置きの1文で帰属を示し、内容は箇条にする。** 「EFSA の結論は次の3つです［3］。」＋箇条（caffeine l.84〜89 が既にこの形）。箇条の各項目に「としています」を付けなくてよい。
- **見出しで帰属を示す。** 「睡眠ガイド2023 の目安は？」のような見出しの直下は、1文目で機関名を出せば、その節の中で毎文くり返さなくてよい（ただし (b) の条件は同じ）。
- **文末の言い方は、「書いています／としています／とあります／〜です（A による）」を混ぜてよい。** 同じ文末の連続を避けるため。

### 短くしてよいもの
- 入れ子の伝聞（「A は、B が…としていると書いています」）は、2文に分けてよい。「A は B の資料を引いています。B によると…」。
- 原文が長い引用は、抜粋にしてよい（原則3の条件つき）。

### 必須で残すもの
- **効能・リスク・安全・推奨量・研究結果の文には、同じ文か、直前の前置き・見出しに機関名（または論文の著者・年）を置く。** 当社の地の文にしない（D0013 の理由「推奨・効果の記述」、checklist 1章）。
- **原文自体の伝聞・留保**（e-ヘルスネットの「といわれています」、ガイドの「可能性がある」「推定される」）は、当社の伝聞を外しても残す。
- **複数の機関を1文にまとめない**（checklist 6章 0033「機関ごとに範囲を分けて書く」）。共通点を言うときも「3機関とも400mgという数字を示している。言い方は表のとおり違う」のように、違いへの参照を付ける。
- **当社の整理・換算・当てはめ**は、それと分かる目印を付ける（「当社の整理では」「つまり」「（当社が当てはめたもの）」）。skincare l.46 の「環境省の原文に『通勤』『昼休み』という言葉はなく、…当てはめたものです」は、この目印の良い例で、短くしても残す。

### OK 例（当社の文で）
- Before（sleep l.89）: 「ガイドは、睡眠時間が睡眠の「量」を反映する指標だとすれば、睡眠休養感（睡眠で休養がとれている感覚）は睡眠の「質」を反映する指標だ、としています。」
  After（OK）: 「睡眠ガイド2023 では、睡眠時間は睡眠の『量』の指標、睡眠休養感（休めたと感じるかどうか）は『質』の指標です［1］。」— 帰属が文頭に移っただけで、内容・出典は同じ。
- Before（sleep l.136）: 「e-ヘルスネットは、睡眠不足が長引くと、むしろ眠気を自覚しにくくなることがわかっている、昼間に強い眠気があり、…受けることが大切だ、としています［4］。」
  After（OK）: 「e-ヘルスネットによると、睡眠不足が長引くと、かえって眠気を自覚しにくくなります。昼間に強い眠気があり、居眠りなどで仕事に支障がある場合は、睡眠障害の専門医療機関で検査を受けることが大切だ、としています［4］。」— 同じ段落・同じ機関なので、2文目の主語は省いてよい。
- そのまま残してよい当社の地の文: sleep l.90「時計で測れる睡眠時間と、朝の『休めたかどうか』の感覚。この2つを、自分の睡眠を振り返る物差しにすることができます。」— 効能・安全を言っていない、読み方の提案なので伝聞は要らない。caffeine l.115「つまり、日本の行政の食品の資料は、海外の機関の目安を紹介する形をとっています。」も「つまり」で当社の整理と分かる。

### NG 例
- caffeine l.178「睡眠ガイド2023は、夕方以降に100mg 以上のカフェインを摂ると、入眠困難や徐波睡眠（熟睡）の減少、中途覚醒の増加が生じる、とし、…」
  → NG: 「夕方以降に100mg 以上摂ると、深い眠りが減ります。」— 主体が消えて当社の断定になり、出典も落ちる。
  → OK: 「睡眠ガイド2023 によると、夕方以降に100mg 以上を摂ると、寝つきにくくなる、深い眠り（徐波睡眠）が減る、夜中に目が覚めやすくなる、とされています。ガイドは夕方以降は控えるよう勧めています［11, p.32〜33］。」
- sleep l.104 の e-ヘルスネット「20℃前後…『といわれています』」→ NG:「寝室は20℃前後、湿度40〜70%が適温です。」— 原文自体の留保（といわれています）が消え、基準のように読める。
- 段落の中で別の機関を挟んだあとに主語を省く → NG: 「EFSA は1日400mg まで…としています。カナダ保健省は…としています。就寝前の100mg で睡眠に影響することがあります。」— 3文目が EFSA かカナダか当社か分からない。

## ② 本文中の出典番号［n］の置き場所

### 変えてよいもの
- **段落の最後に1回にまとめてよい。** 条件は、その段落の文がすべて同じ出典（または同じ出典の組）から来ていること。caffeine l.80 のように1段落が FDA［1］だけなら、段落末の［1］1回で足りる。
- **1文に［1］［3］［4］と並ぶ場合は、［1, 3, 4］のように1つの括弧にまとめてよい。**
- **PDF のページ番号は、番号の括弧の中に入れてよい**（「［11, p.32］」）。文中に「PDF p.32」を裸で置かない。「PDF のページ番号で示す（冊子の印刷ページとは異なる）」の説明は、参考資料の見出しの下に1回書けばよい（caffeine l.132 が既にそうしている）。
- **ページ番号を本文から外し、参考資料の各項目に「本文で使ったページ」をまとめて書く形も可。** ただしその場合は、04-outline（または各案件の作業メモ）に「本文のどの文がどのページか」を残す。レビュー部が照合できなくなるため。
- 表は、列の見出し（caffeine l.97 の「米国 FDA［1］」）か表の直前の1文に番号を置けば、セルごとに付けなくてよい（今の形のまま）。

### 短くしてよいもの
- 同じ段落で同じ番号をくり返している箇所（例: caffeine l.80〜81 の［1］の連続）は、段落末の1回にしてよい。

### 必須で残すもの
- **1つの主張に、必ず1つ以上の番号が読み取れること。** 出典を減らすのではなく、置き場所を変えるだけ（CLAUDE.md 5章、checklist 6章「医学的記述は…出典URLと確認日を残す」「成分の一般的な説明にも出典を付ける」）。
- **出典が混ざる段落では、番号は文ごと（または機関ごと）に付ける。** 段落末にまとめると、どの機関が何を言ったかが混ざる（checklist 6章 0033）。
- **数値（量・割合・件数・価格・含有量）のある文は、その文の末尾に番号を付ける。** 段落が単一出典なら段落末でよいが、数値が2つ以上の出典から来るときは文ごと。
- **価格・内容量・定期購入の条件など、変わりうる数値の確認日は本文のその数値の近くに残す**（CLAUDE.md 5章、checklist 5章）。例: aga-selfcare-vs-clinic l.63「第1類医薬品2製品の内容量・価格が2026年9月28日」、mens-bb-cream・mens-toner の価格と定期コースの条件。
- **出典の確認日そのもの**は、参考資料の一覧（見出しの下の「すべて2026年10月9日に当社が確認」、または各項目）に必ずある状態にする。本文の冒頭から消してよいのは、一覧に同じ日付があるときだけ。
- **企業が発行した資料・企業所属の著者・研究の資金**は、本文の使った箇所と参考資料の両方に書く（checklist 6章 0020）。例: skincare l.83「資生堂の研究者による」、l.84「P&G 所属の著者ら」、caffeine l.80 の IAFNS の資金の段落（0032 レビュー）。これは出典番号の整理で消さない。

### OK 例
- caffeine 先に要点 l.67 の「…カナダ保健省は「推奨する1日の最大摂取量」です［1］［3］［4］。」→「…です［1, 3, 4］。」
- caffeine l.118「…と書いています［11］PDF p.32。」→「…と書いています［11, p.32］。」

### NG 例
- sleep の先に要点（l.66 付近）「…医師に相談する目安です［1］［2］［7］。」を、要点の箱の末尾に「（［1］［2］［4］［7］）」とまとめる → NG。睡眠ガイド・e-ヘルスネット・海外の機関のどれが何を言ったかが分からなくなる。
- 確認日を参考資料の一覧からも消し、ページ下のフッターの「更新日」だけにする → NG。更新日は記事の日付で、出典を確認した日ではない。

## ③ 否定・念押しの文（「〜ではありません」「〜は勧めません」等）

### 変えてよいもの
- **否定を、事実の形に言い換えてよい。** 「どちらが正しいという話ではありません」→「国によって基準の置き方が違います」。
- **範囲の断り（「今回確認した範囲では見つかりませんでした」）の前置きは、記事の末尾の「この記事の作り方」に1回だけ書き**（「この記事で『確認した資料には無い』と書いたものは、参考資料の範囲で探した結果です」）、本文では「確認した資料には、〜は見当たりませんでした」と短くしてよい。

### 短くしてよいもの（1回にまとめる・削ってよい）
- 同じ趣旨の否定が段落内・近い位置で続く箇所は1文にまとめる。skincare l.162 の3文は1文にしてよい（下の OK 例）。
- **まとめ（要点の箇条）でくり返す免責**は、本文と disclaimer にあれば削ってよい。例: skincare l.183「この記事は、特定の商品や成分の効果を示すものではありません。」は、l.162 の運営者の節と l.249 付近の disclaimer にあるので、まとめからは削ってよい。
- リンクの無い記事の「商品のランキングや『おすすめ』の記事ではありません」（oral-care・whitening・body-odor の l.61）は、末尾の「この記事の作り方」へ移すか、削ってよい。
- 表の前の「どの機関の数字が正しいかを決める表ではありません」（caffeine l.95）は、機関どうしの表なら削ってよい。

### 必須で残すもの
- **運営者の使用品の節: 「効果を示すものではない」趣旨を1回**（0014 レビュー #6・l.168 の維持）。あわせて、自費購入・無償提供なし・報酬なしの申告（0012・0013 レビュー）と、その節の近くのリンク無しの明示（日付つき）。
- **医薬部外品の効能を載せない理由**（skincare l.165「効能は、公式ページで『効能・効果』の欄として確認できなかったため、載せていません」）。載せない理由が消えると、効能を省いた意図が読めない（0014 追記審査、checklist 1章）。
- **商品・成分・医療機関を並べた表の「順位ではない」と並び順の基準**（checklist 2章、0028、D0003）。医療機関では「掲載していない医療機関より優れているという意味ではない」旨も（checklist 4章）。短くしてよいが消さない。
- **「当サイトは個人輸入を勧めません」**（minoxidil-finasteride-guideline l.212）などの、未承認薬・個人輸入・海外製品の購入を案内しない旨の1文（checklist 4章の未承認医薬品の扱い）。1回でよい。
- **末尾の `disclaimer`**（checklist 7章）。本文の「この記事は診断をするものではありません」は、disclaimer があれば本文からは削ってよいが、受診の目安の節では「迷うときは相談を」の肯定形を残すことを勧める。
- **根拠が無いことの明示**（「確認した資料には、一般の健康な男性向けの洗顔の公的な推奨は見当たりませんでした」）。これを消すと、本文の目安が公的な推奨に見える。短くしてよいが消さない。

### 否定そのものが NG になる場合
- **効果を否定で言い切る文は、断定として NG**（0014 レビュー #6 の「特定の商品や成分で見た目が大きく変わる、という話ではありません」が「出典の無い否定の断定」とされた）。読みやすさのために否定を足すときも、「効果がない」「意味がない」と当社が言い切らない。「この記事は〜の効果を示すものではありません」のように、記事の範囲の説明にとどめる。

### OK 例
- skincare l.162 Before: 「使っている事実の記録であり、選び方の基準を示すものではありません。感想や効果は書いていません。運営者の使用は、効果を示すものではありません。」
  After（OK）: 「使っている事実の記録で、選び方の基準や効果を示すものではありません（感想・効果は載せていません）。」
- skincare l.67 Before: 「選ぶ基準が違うだけで、どちらが正しいという話ではありません。」→ After（OK）: 「日本と米英では、基準の置き方が違います。」

### NG 例
- skincare l.162〜170 の否定をすべて削って「運営者が使っているのは次のものです。」だけにする → NG（効果を示さない旨・自費購入・リンク無しが消え、使用品の紹介が推奨に読まれる。適正広告基準の解説 PDF p.21『私も使っています』、0029）。
- skincare l.28「…今回確認した範囲では見つかりませんでした。ここは、上の学会の記述…を目安に、…という書き方にとどめます。」を「洗顔は、強くこすらず、洗いすぎず、十分に流しましょう。」にする → NG（にきびのある人向けの学会の記述が、一般の男性への推奨に格上げされる）。

## ④ PR 表示・「この記事について」の位置と長さ

### 動かせないもの（冒頭に残す）
- **`pr-badge`**: 記事の冒頭（h1 の上、今の l.55）。文言はリンクの有無で決まった2種類のまま（checklist 3章・7章）。小さくしない・色を薄くしない（運用基準 PDF p.8 カ・キ）。
- **アフィリエイトリンクを描画している記事では、リンクの数と場所の1文**（例: mens-bb-cream l.62「この記事には、アフィリエイトリンク（広告）が1か所あります（「商品の一例」の節）。」）。リード直後に1文で置く。長い説明の中に埋もれさせない（運用基準 PDF p.8 キ）。広告の節の見出しや枠にも「広告」の表示を残す（0013 レビュー「各枠に『広告：』」）。
- **運営者の使用品を商品名つきで載せる記事（リンク無し）**: 冒頭に1文「記事の後半に、運営者が使っているものを商品名つきで載せています（リンク・提供・報酬なし）。」程度。詳細（日付、自費購入の申告）はその節の側に置く（skincare l.170 が既にある）。冒頭の文は短くしてよいが、消さない。
- **クリニック名・料金を載せる記事**: 掲載基準（ランキングなし・並び順の基準・報酬と無関係・掲載外の院より優れている意味ではない）は、院の一覧の直前（または一覧の中）に必ず置く。冒頭からは一覧への1行の案内に縮めてよい（D0003、checklist 4章）。

### 後ろへ移してよいもの（末尾の「この記事の作り方」の箱、または参考資料の見出しの下へ）
- 「本文中の［1］などは、末尾の参考資料の番号です」
- 「確認日は、すべて◯年◯月◯日です」（参考資料の一覧に同じ日付があることが条件。②を参照）
- PDF のページ番号の説明、英国 NHS・米国 CDC 等が一般向けページである旨、要旨（抄録）で確認した論文の注記（protein l.62）
- 「研究の資金と、企業が作成した資料であることは、参考資料に書き添えました」という案内の文（本文の使った箇所の記載は残す。②）
- 記事の範囲の説明（「この記事は、カフェインの働きや効果を紹介するものではありません」「薬の入手方法や用量は扱いません」「商品名・販売名・企業名は載せていません」）
- リンクの無い記事の「商品名は載せておらず、商品・通販へのリンクも置いていません（日付時点）」
- 箱の置き場所は「まとめ」の後・「参考資料」の前。目次に載せ、byline の「記事の作り方」から about.html だけでなくこの箱にも飛べるとよい（任意）。

### 長さ
- 冒頭に残すもの（pr-badge を除く）は、合わせて **1〜2文**（目安80字以内）。リードの段落に混ぜず、別の1行にする。
- 末尾の箱は長さの制限を設けないが、箇条にして1項目1文。

### 移したあとに必ず確認すること
- **リンクを後から足すとき**: 末尾に移した「リンクを置いていません」の文も、pr-badge の文言・冒頭の1文と一緒に直す（0009 レビュー 持ち越し9、checklist 7章）。置き場所が2か所に分かれるので、差分審査で両方を見る。
- **冒頭の文と末尾の箱が矛盾しないこと**（運用基準 PDF p.8 イ: 冒頭と文中で広告かどうかの言い方が食い違うと不明瞭）。
- `disclosure.html` の記述と矛盾しないこと（checklist 7章）。

### OK 例
- caffeine l.62（8文）→ 冒頭は削除（pr-badge「当サイトはアフィリエイト広告を利用しています」は l.55 に残る）。8文はすべて末尾の箱へ。リンクも商品名も無い記事なので、冒頭に必須の文は無い。
- skincare l.62（5文）→ 冒頭は「記事の後半に、運営者が使っているものを商品名つきで載せています（アフィリエイトリンクなし）。」の1文だけ残し、［n］・確認日・NHS/AAD の説明は末尾の箱へ。

### NG 例
- mens-bb-cream l.62 の「アフィリエイトリンク（広告）が1か所あります（『商品の一例』の節）」を末尾の箱へ移す → NG（広告の明示を末尾に置くことになる。運用基準 PDF p.8 オ）。
- pr-badge を目次の下やフッターへ移す、文字を小さくする → NG。

## ⑤ 疑問形の見出し・語りかけ・共感表現

### 変えてよいもの（使ってよい）
- **疑問形の見出し**。条件は、直下の1文で「資料にはこう書かれている」「資料が無い」と答えること。答えが当社の断定にならないこと（①）。
- **読者の場面の描写と、問いかけ**（「〜という経験はありませんか？」）。caffeine l.59「朝に1杯、会議の前に1杯、午後にもう1杯。」や sleep l.59 の「『平日は6時間を切る日が続いている』」は良い例で、残してよい。
- **共感の一言**（「気になりますよね」「迷うのは自然なことです」）。1節に1回程度。
- **「あなた」**の使用（aga l.66「あなたの状況別」の程度）。
- **受診を勧める語りかけ**（sleep l.139「いびきを指摘されている方が睡眠薬や寝酒を考えるときは、まず医師に相談してください。」）。受診・相談を勧めるのは煽りではない。

### 線（NG）
- **効能の答えを予告する疑問形**: 「〜で睡眠の質は上がる？」「〜でAGAは治る？」のように、見出しの問いが効能で、本文の答えが「上がる・治る」に読める形。問いを「資料には何と書かれている？」「目安はどれくらい？」「どこまで分かっている？」に変える。
- **恐怖訴求**: 「放置すると危険」「手遅れになる前に」「このままでは〜が進行します」。症状・リスクは資料の文言と条件のまま、受診の目安として書く（0032 04-outline の grep 語「放置|手遅れ|怖|恐」は今後も差分審査で使う）。
- **同調圧力・焦り**: 「みんな始めている」「まだ〜していないの？」「今すぐ」。
- **不安の直後に商品・CTA**: 不安の描写と商品枠・リンクを同じ節に置かない（checklist 1章「症状・体の働きを対象にする成分説明の近くに CTA を置かない」、D0013）。
- **場面の描写を体験談に見せない**: 1文目から読者の想定と分かる書き方にする（0031 レビュー #10「この記事は、次のような疑問を持った方を想定しています」）。「（30代・会社員）」のような属性ラベルや人名を付けない（口コミの捏造に見える。checklist 6章）。運営者の体験は owner-inbox で取材したものだけ（CLAUDE.md 5章）。
- **猫のキャラクターに語りかけさせない**（D0011、checklist 6章）。吹き出し・猫の台詞は記事本文で使わない。
- **title・h1 の疑問形**は可（caffeine のタイトルが既に疑問形）。ただし答えを先取りした誇大（「〜で変わる？答えはYES」）は不可（checklist 7章）。

### OK 例
- caffeine の見出し「日本：食品の安全の面と、睡眠の面を分けて読む」→「日本の目安はある？」＋直下「食品の安全の面では、国としての目安は設定されていません（厚生労働省［5］）。睡眠の面では、睡眠ガイド2023が『400mgを超えないように』と書いています［11, p.32］。」
- skincare の見出し「紫外線対策：日焼け止めの表示・場面・塗る量」→「日焼け止めは、どれくらい塗ればいい？」＋直下「環境省のマニュアルの目安は、顔ならクリーム状でパール粒1個分、液状なら1円硬貨1個分を、2回に分けて重ねる量です［3］。」（skincare l.111。「液状なら」の条件も落とさない）

### NG 例
- 「カフェインの摂りすぎ、放っておくと危ない？」→ NG（恐怖訴求。caffeine の節は「摂りすぎのサインと、受診の目安」の内容のまま、見出しは「どんなときに相談する？」にする）。
- 「睡眠サプリで、ぐっすり眠れる？」→ NG（効能の問い。sleep の該当節は「睡眠サプリの表示は、どこを見ればいい？」）。
- melatonin 型の冒頭を「海外出張の前に時差ぼけ対策を調べていたら…」と1人称で始める → NG（0031 #10 で直した形に戻ってしまう）。

## ⑥ 専門用語の言い換え

### 変えてよいもの
- **語順を「平易な語（用語）」にしてよい**（01 の皮膚科学会の型）。例: 「経表皮水分蒸散量（皮膚から水分が逃げる量）」→「皮膚から水分が逃げる量（経表皮水分蒸散量）」。
- **用語の定義を、本文の外の小さな箱（「用語」「（注）」）に出してよい。**
- **用語を省き、平易な語だけにしてもよい場合**: 本文で1回も用語を使わないなら可。ただし原文の引用（「」内）と表の原文の列は用語のまま。

### 線
- **言い換えは「何であるか」（定義・分類）にとどめ、「何をするか」（働き・効果）を足さない。** 言い換えで動詞「守る・整える・促す・高める・改善する・修復する・届ける」が入ったら、効能の暗示を疑う（checklist 1章: 化粧品は56項目の範囲、サプリは効能を言えない）。
- **評価語を足さない**: 「最も信頼できる研究」「昔ながらのよく効く薬」「安全な量」。
- **定義の出典を保つ**: 言い換えの元が公的資料・JCIA の用語解説なら、その表現に寄せる（checklist 6章「成分の一般的な説明にも出典」）。当社の比喩（「毛の工場」型）は、効能・作用機序の説明に使わない。
- **「浸透」「肌の奥まで」**は、言い換えでも使わない（JCIA E3、checklist 1章 0028）。
- **区分の言い換え**: 医薬部外品を「効果が認められた化粧品」などと言い換えない。区分を説明するときは「皮膚に使う医薬品もある」を落とさない（checklist 6章）。

### OK 例
- caffeine l.111 付近「一生涯摂り続けても健康に悪影響が生じないと推定される一日あたりの摂取許容量（ADI）」→「毎日一生摂っても健康に悪影響が出ないと推定される1日の量（一日摂取許容量、ADI）」— 「推定される」を残している。
- sleep l.139「ベンゾジアゼピン受容体作動薬に分類される睡眠薬」→「睡眠薬の一種（ベンゾジアゼピン受容体作動薬）」。
- blue-light-glasses の「系統的レビュー」→「複数の研究を決まった手順で集めてまとめた論文（系統的レビュー）」。
- caffeine l.178「徐波睡眠（熟睡）」→「深い眠り（徐波睡眠）」。

### NG 例
- EFSA の「安全上の懸念を生じない」（caffeine l.84〜89）→「安全な量」「400mgまでは大丈夫」→ NG（安全性の保証に読まれる。checklist 1章「安全」）。OK は「安全上の懸念はないとされる量（EFSA）」。
- ADI の言い換えで「推定される」を落として「健康に悪影響が出ない量」→ NG。
- skincare l.79 の「エモリエント剤（油溶性成分）」→「肌のバリアを守る油分」→ NG（効能の追加）。OK は「油分で肌をおおう成分（エモリエント剤）」（JCIA の用語解説の説明の範囲）。
- 「角層（皮膚のいちばん外側の層）」は OK、「成分が肌の奥まで届く」は NG（JCIA E3）。

## ⑦ 要点の箇条書きの短縮

### 変えてよいもの
- 1項目1〜2文にしてよい。本文の比較表を要点で文章として再現しない（01 原因B）。詳細は「→表」「（杯数の節）」で本文へ送ってよい。
- 機関ごとの原文の言い方を、要点では省いて「言い方と対象が違う（表）」にまとめてよい。

### 必須で残すもの（要点・まとめ・見出し・meta description・SNS 告知のすべてに適用）
- **主体**（どの機関か。複数なら「米国・欧州・カナダの公的機関は」）
- **対象**（「健康な成人」「妊婦を除く」「成人」）
- **条件**（「1日を通して」「夕方以降」「〜が続き、生活に影響しているとき」）
- **留保**（「目安」「個人差がある」「可能性がある」）
- **行政の回答・届出表示の留保**（checklist 6章 0026「表・まとめ・要点にも付ける」）
- **副作用の数値の対象・条件**（checklist 6章 0025）、**症例の転帰の例外**（0031・0033）
- **出典番号**（1項目に少なくとも1つ）
- 要点の短縮で、本文より強い言い方にならないこと（原則4）。

### OK 例
- caffeine 先に要点の1項目目（l.67、233字・4文）→「米国・欧州・カナダの公的機関は、健康な成人について1日400mgという数字を示しています。ただし言い方と対象は機関ごとに違い（表）、FDA は個人差が大きいとしています［1, 3, 4］。」— 主体・対象・個人差・出典が残っている。
- sleep 先に要点の1項目目 →「睡眠ガイド2023 の目安は、成人で6時間以上（個人差あり）。朝の『休めた感じ』（睡眠休養感）も指標にしています［1］。」

### NG 例
- 「カフェインは1日400mgまでが目安です。」→ NG（主体・対象〈健康な成人・妊婦を除く〉・個人差・出典が落ち、当社の断定になる）。
- 「6時間以上寝ましょう。」→ NG（「個人差があるが」「目安として」と、ガイドという主体が落ちる）。
- sleep の受診の目安を「眠れない・日中眠いときは受診を。」→ NG（「生活を見直しても」「続き、生活に影響しているとき」の条件が落ち、受診基準が広がる。逆向きの不正確も事実性の問題として扱う）。

## 差分審査で見る点（編集部のリライトの提出物に求めること）

1. 04（またはリライトのメモ）に、変えた文の Before/After を一覧にし、それぞれ上の①〜⑦のどれに当たるかを書く。
2. 機械チェック（レビュー部も同じものを流す）:
   - 削られた［n］が無いこと（記事ごとに［n］の番号の集合が変わっていない。段落末へまとめた場合は、数ではなく集合で比べる）
   - 「可能性|個人差|目安|推定|といわれ|とされ」の出現数が大きく減っていないこと（減った箇所は理由を書く）
   - 「放置|手遅れ|怖|恐|必ず|確実|おすすめ|浸透|改善|安全な」が増えていないこと
   - pr-badge の位置と文言、disclaimer、運営者の使用品の節の否定1回・自費購入の申告・リンク無しの明示が残っていること
3. 事実・数値・出典・原文の引用は変えない（00-brief スコープ4）。変える必要が出たら、文体のリライトとは別の差分として出す。
4. 本文を変えたら `scripts/site_data.json` の `updated` を更新し、X の予約投稿の文面と記事が合っているかも見る（checklist 6章）。
