## 1. 共通で変えたこと

- 冒頭の「この記事について」を削り、まとめの後に `<h2 id="method">この記事の作り方</h2>` を新設した（skincare は関連記事の前、mens-selfcare は参考資料の前）。順番はガイド6章どおり（［n］と確認日 → 範囲 → 企業の資料 → 商品の扱い）。
- リードを1段落にした（読者の場面 → この記事で分かること）。
- h2 を読者の疑問の形にし、直下の1文で答えた。効能の問い・恐怖の問いは使っていない。
- **id はすべてそのまま**（他記事からのアンカーを grep で確認: skincare は `#basic #moisture #male-skin #sunscreen #spf-pa #amount #category #choose #visit`、mens-selfcare は `#sleep #category`）。新しく足した id は `method` だけ。
- 他記事が見出し名を引いている h3（`#male-skin`「男性の肌の特徴と、ひげ剃り」、`#spf-pa`「SPFとPAは何の数字か」、`#amount`「塗る量と塗り直し」、`#choose`「続けやすい選び方のポイント」、mens の `#category`「1. 区分を見る：…」）は、見出しの文言も変えていない。
- pr-badge（l.55）、disclaimer、参考資料の一覧、表の中身は変えていない（skincare の成分の表は、セルの文言を変えず、リンクの文言「別記事」だけ直した。T-14）。
- ［n］は［3, 5］［19, 20］［6, 7, 8］の形にまとめた。表の中の［1］［3］［4］は、表には手を入れない方針でそのまま。
