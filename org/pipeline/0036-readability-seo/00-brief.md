# 00 発注書: 読みやすさの改善（文体ガイド）と SEO 対策

- 案件ID: 0036
- ステータス: 進行中
- 起票日: 2026-10-09
- 起票理由: オーナー「サイトのコンセプトは良いが、文章自体は少し硬くて読みづらい。日本語で人気のサイトを分析して書き方を分析し、既存記事・今後の記事に反映させて。同時にSEO対策も実施して。」（2026-10-09）

## 目的
- 中立・出典つき・言わない側、というコンセプト（堀）は保ったまま、読みやすさを上げる（滞在・回遊・検索順位・CTR）
- 技術・内容の両面で SEO の改善点を洗い出し、実施する

## スコープ
1. **文体の分析（リサーチ部）**: 日本語で人気の健康・美容・生活情報サイト（例: 医療・健康系メディア、男性向けメディア、生活情報メディア、公的機関の一般向けページで読みやすいもの）の書き方を、具体的な文で分析。文の長さ、結論の位置、見出しの付け方、箇条書き・表・図の使い方、語りかけ、専門用語の言い換え、要点ボックス、FAQ、漢字とひらがなのバランス、1段落の長さ、出典の見せ方
2. **文体ガイド（経営企画が確定）**: `org/style-guide.md` に、分析を当社のコンセプト（煽らない・断定しない・出典つき）に合わせて落とし込んだ具体的なルールと、当社の既存記事の Before/After の例
3. **SEO 監査（分析部）**: 全ページの title・meta description の長さと内容、h1/h2 の構造、内部リンク、構造化データ（FAQ 等の可否を含む）、画像の alt、表示速度に効く要素、パンくず、sitemap、Search Console の状況（オーナーのスクショ待ち）。改善案を優先度つきで
4. **実施**: 技術 SEO は経営企画が `scripts/build_site.py` 等で。既存記事の読みやすさのリライトは編集部が数本ずつ。**事実・出典・数値・言い回しの法的な線は変えない**（レビュー部が差分で確認）
5. **今後の記事**: 編集部の定義（`.claude/agents/editor.md`）と `org/templates/04-outline.md` に文体ガイドの参照を入れる

## やらないこと
- 煽り・断定・体験談の捏造・効能の言い切りで「読みやすく」すること
- 競合の文章の転用
