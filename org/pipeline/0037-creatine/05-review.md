## 持ち越し論点の最終判断

1. **ISSN 2021 の Alzchem 関係者の人数（04 質問1）**: **5名（委員4名＋委員長1名）で確定。** ローカルの写しと PMC 版で照合した。記事はこのままでよい。01 の論点3・要約の「4名」は、リサーチ部の記録の誤りとして残す（指摘 #9）。
2. **MSD の推奨事項2文の一字一致の引用（「かなり安全とみられますが」を含む。04 質問2）**: **このまま認める。** 理由は次のとおり。
   - (a) 商品名もリンクも無いページで、第三者（MSD マニュアル、発行者を明記）の文を `<blockquote>` で一字一致に引いている。当社の地の文で安全と言う箇所は無い（05-style-rules ①原則2）。
   - (b) 同じ文の後半に「避けるべき」がある。2文目の前半だけを削ると、MSD の見方が実際より注意側に寄って見える（checklist 6章「機関ごとに範囲を分けて書く」）。
   - (c) 引用は2文だけで、出典も明記されている（著作権法32条の引用の範囲）。
   - **条件**: 「かなり安全」の語は、要点・まとめ・meta description・X 告知・表に持ち出さない（今の版は持ち出していない）。抜粋するなら、「腎機能障害の既往がある人や…避けるべき」の部分を必ず残す。
3. **01 に無い原文の記述3点の追加（04 質問6）**: **3点とも原文と一致したので認める**（上の「前工程の検証」）。どれも、一方の見方だけが残るのを防ぐための追加で、checklist 6章の趣旨に合う。今後の運用として、編集部が 01 に無い出典の記述を足したときは、04 に原文の行番号を残すこと。今回は質問6に行番号があり、照合できた。
4. **効能の語を含む引用・要約の扱い（04 質問3）**: **認める。** ISSN の立場1は「有効と位置づけています（当社の要約）」、EU の表示は英語の原文を blockquote にしてから当社の要約、NCCIH は「may somewhat enhance」を添えている。どれも機関名と条件が付いていて、主語を「クレアチンは」にした当社の効能文は無い。商品名もリンクも無いので、医薬品等の広告の3要件（誘引性・特定商品名・認知性）のうち特定商品名を満たさない。ただし今後この記事、または同じページから辿れる位置にクレアチン商品のリンクを置く場合は、D0013 と checklist 4章の推せん条項が当たる。その場合、ISSN の立場1・EU の表示の要約・NCCIH の効果の記述は、ページ全体から削る必要がある。
5. **「医療機関（皮膚科）で相談できます」（04 質問5）**: **残してよい。** 受診先の一般名だけで、院名もリンクも無いので、誘引性・特定性は無い。判断⑦にも反しない（任意で「医療機関に相談できます」に縮めてもよい）。
6. **samecat（04 質問4）**: build 後は protein-guide が出ていないので対応不要（上の質問3）。
7. **fatigue-recovery から本記事への関連記事の行（04 質問7）**: 経営企画の判断事項。法令上の問題は無い（fatigue-recovery はアフィリエイトリンクを描画しない記事）。
