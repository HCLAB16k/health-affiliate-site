# 0055 カードの説明文（site_data の desc）の書き直し — 04 編集部

- 日付: 2026-10-30
- 発端: オーナー指摘（2026-10-30）「トップ・カテゴリの記事カードの説明文が読者目線でない。『商品のリンクなし』は要らない」。同日の追加指示「途中で切れた終わり方は不可。最後まで言い切り、終わり方を記事ごとに変える」
- 基準: `org/style-guide.md` 7章「カードの説明文」
- 変更範囲: `scripts/site_data.json` の articles 32件の `desc` のみ。title・他のキー・記事 HTML・カテゴリの lead には触れていない。build と git は実行していない（経営企画が行う）

## 前工程の検証

- 各記事の title と「先に要点」（`id="summary-top"` の直後のリスト）を Grep で読み、説明文の項目がすべて記事の要点か見出しにあることを確かめた。記事に無い項目は入れていない。
- 旧 desc にあった「〜は見つからなかった」「推奨度D」「（2017年版）」などの事実の言い切りと括弧の注記は、カードでは書かない方針（ガイド）のため外した。どれも記事の本文と要点には残っている（記事 HTML は変更していない）。
- 決定事項との照合:
  - D0018（ed-otc-tadalafil・nocturia-night-urination）: 医学用語（勃起不全・夜間頻尿・排尿日誌）だけで書いた。「薬局で買える」「すぐ手に入る」のような入手に誘う言い方はしていない。「勃起不全（ED）」の括弧はガイドの「括弧の注記なし」に合わせて外し、医学用語の「勃起不全」だけにした。
  - D0015（glp1-diet）: 「なぜ勧められないのか」「学会などの注意」「救済制度の扱い」の、注意を伝える形にした。クリニック・入手の話題には触れていない。
  - アシュワガンダ・メラトニン: 「研究の限界」「肝臓への影響の報告」「扱いの違い」「個人輸入の注意点」に限った。入手の方法・購入先・効き方に関わる言い方はしていない（メラトニンの時差ぼけの評価はカードから外した。使う目的の示唆になりうるため）。

## 書き方の方針

- 1件1文（2文まででよいが、途中で切れる文を避けるため1文にした）。全角おおむね45〜68字。
- 機関名・資料名は入れていない（32件とも0）。「ガイドライン」「学会など」「国内外の資料」は一般名詞として使った。
- 終わり方は4種を回した。「整理しました」「説明します」「まとめました」「が分かります」。公開日の新しい順（一覧の並び）でも、JSON の並びでも、隣り合う2件が同じ終わり方にならないよう割り振った。
- 「商品の紹介なし」「リンクなし」「掲載なし」は全件から外した。広告の有無は記事の pr-badge と作り方の箱で示している。
- 煽り・効能の暗示・最大級の語は使っていない。「効果がないと感じた」（hair-tonic-review）は title の言葉に合わせた、読者の感じ方の表現。
