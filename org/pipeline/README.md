# 案件パイプライン

1案件 = 1フォルダ（`NNNN-slug/`、NNNN は連番）。中身は工程順に:

```
00-brief.md     経営企画   発注書・経営判断ログ・ステータス
01-research.md  リサーチ部
02-products.md  商品企画部
03-channel.md   プラットフォーム戦略部
04-outline.md   編集部（構成案＋執筆メモ）
05-review.md    レビュー部（PASS / REVISE / BLOCK、再審査は追記）
```

記事本体は `articles/` に置く（案件フォルダには置かない）。

## ステータスの流れ
進行中 → （差し戻し中 ⇄ 進行中）→ オーナー承認待ち（PR作成済み）→ 公開済み（PRマージ）
どこからでも → 保留（BLOCK、差し戻し上限超過、オーナー判断待ち）

候補テーマは `backlog.md`。
