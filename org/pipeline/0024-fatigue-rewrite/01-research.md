1. **機能性表示食品の届出表示を、消費者庁データベースの原文で確認できなかった。** 届出情報検索（https://www.fld.caa.go.jp/caaks/s/cssc01/ 、2026-10-05 更新と案内あり）は Salesforce の JS 画面で、curl・WebFetch とも本文を取得できなかった（WebFetch は「Sorry to interrupt / CSS Error」）。下の F30〜F33 はメーカー発表の写しで、DB 原文とは照合していない。
   - 対応案A（推奨）: オーナーがブラウザで DB を開き、届出番号 2〜3件の「表示しようとする機能性」と届出の状態（撤回されていないか）を写す（owner-inbox に積む）。照合できた番号だけを記事で使う。
   - 対応案B: 記事では特定の届出番号を出さない。消費者庁リーフレット（F28・F29）の範囲で「届出表示の読み方」と「届出番号で DB を引ける」ことだけを書く。
   - **0023（睡眠）でも同じ壁に当たる見込み**（GABA・テアニン・グリシンの届出表示）。両案件をまとめて判断するほうがよい。
2. **届出番号を出すことが特定商品の紹介にならないか（D0013・checklist 4章の「推せん」条項の類推）。** 届出番号を書くと商品が1つに決まる。効能を説明する記事なので、商品名もリンクも出さない状態でも「その商品の機能性を紹介している」と読まれる余地がある。案Bにするか、案Aでも商品名を書かず、届出番号と届出表示だけにするか、レビュー部の判断がほしい。
3. **「日本疲労学会」の一般向け資料は確認できなかった。** 学会の旧ドメイン hirougakkai.com は 2026-10-07 時点でドメイン駐車ページ（NameBright「Coming Soon」）になっている。疲労の定義は長寿科学振興財団のページ（二次資料、F05）経由でしか確認できない。**このドメインへのリンクを記事に張らないこと**（第三者に渡ったドメインの可能性）。
