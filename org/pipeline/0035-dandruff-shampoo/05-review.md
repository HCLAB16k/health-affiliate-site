## 持ち越し論点の最終判断

1. **04 質問2: 米国の未承認医薬品（日本で未承認）のラベルの用途（Uses）の原文と和訳を載せることは、薬機法68条の広告に当たらないか → 現在の形なら許容する。**
   - 68条は「何人も」承認前の医薬品の「名称、製造方法、効能、効果又は性能に関する広告」を禁じる。広告に当たるかは ①顧客を誘引する意図が明確 ②特定の医薬品の商品名が明らかにされている ③一般人が認知できる状態、の3要件で判断する（手引き R8、checklist 4章）。
   - ③は満たす。②は、本文に商品名は無いが、「ケトコナゾール1%」「NDA 020310」と参考資料の DailyMed・openFDA の URL（テキスト）から、事実上1製品に特定できる。あやしいヤクブツ連絡ネットも、商品名を伏せても認知度等から総合的に広告と判断されうるとしている（`dr_yakubutsu_purchase.txt` l.228）。**よって判断の決め手は①**。
   - ①は満たさないと判断する。理由: (a) 商品・通販・輸入代行へのリンクも入手方法も無い、(b) 用途の引用は「フケだけで脂漏性皮膚炎は入っていない」という**区分の狭さを示す**文脈で、効き目を勧める文脈ではない、(c) l.92「日本での使い方の目安にするものではありません」、(d) 個人輸入の節で「当サイトは個人輸入を勧めません」と厚労省のリスクを書いている、(e) 用法（every 3-4 days 等）を載せていない、(f) X 告知も効能を書いていない。
   - **条件（今後の改変で再審査に戻すもの）**: 製品名・販売名・事業者名を本文に出す／入手方法・価格・輸入代行・通販への言及やリンクを足す／ラベルの用法を足す／「日本でも使える」「効く」方向の評価文を足す／アフィリエイトリンクや医薬部外品の商品枠を同じページに置く。いずれか1つで①の判断が変わりうる。
2. **04 質問3: 電子添文の用法を「患部に塗布する形」とだけ書き、回数を書かないこと → 許容する。** 00 ④（承認効能まで）に収まり、回数・量を書かないので使い方の指示に読めない。l.104 の「使い方は、処方した医師や薬剤師に確かめてください」と組み合わせて、知恵袋の「シャンプーに混ぜる」疑問に、当社が混ぜ方を答えずに応じている。電子添文に無いことを「書かれていません」と事実で書き、「混ぜてはいけない」と出典の無い断定もしていない（01 未確認事項のとおり）。
3. **医薬部外品の効能（2014年通知の原文の範囲）**: l.113・124 は原文どおり、当社の文で効能を言う箇所は無い（l.139 で「どの有効成分でも、表示できる効能は上の通知の範囲」）。l.140 で米国の規則と日本の別表の両方にある成分（ピリチオン亜鉛・サリチル酸）を挙げているが、「数値は比べていません」と書き、商品も無いので、米国での脂漏性皮膚炎の表示を日本の部外品に読み込ませる形にはなっていない。**許容。**
4. **恐怖訴求**: Grep 0件。l.165 の Q31 の引用「おできのようになり、膿んで盛り上がり、痛くなります」は原文の引用で、当社の当てはめ（自己判断でステロイドを塗る前に皮膚科で確かめる）も穏当。ただし「現在はまれ」が同じ段落に無く、表（l.162）にしか無い（指摘 #6、推奨）。NHS の「害はなく、うつるものでもない」、AAD の「多くの人では医療は要らない」を入れ、全体のトーンは落ち着いている。**恐怖訴求なしと判断。**

### 読者目線の講評
- 30代の会社員がフケの続く頭で「ニゾラール 日本」と検索して着いた場合、要点の5行で「米国では個別承認の市販薬、日本では医療用医薬品でシャンプーは見当たらない、日本の薬用シャンプーで言えるのは『ふけ・かゆみを防ぐ』まで、4週間で受診を考える、個人輸入は救済の対象外」まで分かる。「で、自分はどうすればいいか」への答え（今の容器の区分を確かめる → 4週間・赤み・腫れ・顔や体なら皮膚科）も、商品を押しつけずに出せている。競合のランキング記事（部外品で「脂漏性皮膚炎に効果的」）やクリニックの解説より、一次資料で区分を分けた点ではっきり上。
- 弱いところは2つ。(1) 受診の表が5機関あり、忙しい読者には「結局いつ行くのか」が一拍遅れる。h2 直下の1文（l.155）が NHS の目安で答えているので形は良いが、指摘 #12 の「急ぎではない」の温度があると、皮膚科へのためらい（知恵袋）に寄り添える。(2) 米国の制度の節（l.71〜92）は正確だが密度が高い。読者の関心は「日本で手に入るか」なので、現状の順（米国 → 日本）でよいが、表の前の1文で「日本の読者に関係するのは、米国では1%が市販、2%は処方という点だけ」程度の道案内があると読みやすい（任意）。
