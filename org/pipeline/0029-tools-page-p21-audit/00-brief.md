# 00 発注書: tools.html・sale.html の「運営者の使用」表示の監査（適正広告基準の解説 p.21）

- 案件ID: 0029
- ステータス: 進行中
- 起票日: 2026-10-07
- 起票理由: 0028 の事前確認（05-review.md 持ち越し4）。適正広告基準の解説 PDF p.21 は「私も使っています」等の使用経験の広告を原則不可とする（例外: 化粧品等で使用感を説明する場合）。tools.html・sale.html は公開中で、化粧品（ヘアオイル・舌用ジェル等）を「運営者が使っている」として Amazon リンク付きで載せているため、直ちに審査する

## 目的
- 公開中のページが薬機法（医薬品等適正広告基準）に照らして問題ないかを確かめ、必要なら修正・リンクの一時撤去をする

## スコープ
- 対象: tools.html、sale.html（掲載中の全商品。区分ごとに: 化粧品・医薬部外品・医療機器・雑貨）
- 判断してほしいこと: p.21 の原文と、例外の範囲。雑貨・家電（トリマー）や医療機器（電動歯ブラシ等）への適用の有無。「運営者の使用の記録」というページの性質で扱いが変わるか。修正案（例: 使用の事実の書き方、区分ごとの表示、リンクの扱い）
- やらないこと: 新しい商品の追加
