## 持ち越し論点の最終判断

### 04 異議1: 価格を載せた `#otc` に「ミノキシジル外用は推奨度A」を残してよいか → **残せない（必須で削る）**

1. **広告該当性の3要件**（手引きR8 PDF p.266、`mhlw_tebiki_r8.txt` 30717行〜）: 「(1) 顧客を誘引する（顧客の購入意欲を昂進させる）意図が明確であること、(2) 特定の医薬品の商品名（販売名）が明らかにされていること、(3) 一般人が認知できる状態であること」。
   - (2)(3) は既に満たしている（販売名2つを公開ページに掲載）。
   - (1): これまでは「購入情報もリンクも無い成分・区分の解説」と見る余地があったが、今回 **販売名＋価格＋販売場所（メーカー通販名）＋内容量** がそろい、商品の購入判断の材料そのものになった。さらに、この記事の公開 HTML コメントには同じ2製品の ASP リンク挿入位置があり、経営企画メモは `#otc` を第1類医薬品アフィリエイトの受け皿と位置付けて提携申請中（上の異議3）。リンクが無いことだけでは (1) を否定しきれない。
2. **第4の10（推せん）**: 「学会を含む団体が…推せんし…ている等の広告を行ってはならない」（薬生発0929第4号 別紙、`mhlw_tekisei_0000179264.txt` 255〜265行）。解説は「例え事実であったとしても不適当」（薬生監麻発0929第5号 PDF p.28、`mhlw_tekisei_0000179263.txt` 2531〜2537行）。同じ h3 の中で「推奨度Aの治療のうち…購入できるのがミノキシジル5％外用（117行）」→ 製品表 → 価格表 → 「推奨度A（131行）」と並ぶ構成は、学会評価と特定商品・価格を結び付ける典型で、「特定の製品を推薦するものではありません」の注記では足りない（0003 レビューの確定判断、チェックリスト4章79行「距離や注記では足りない」）。
3. **範囲**: チェックリスト4章79行はページ単位。経営企画自身も `org/asp-programs.md` で「0001 のミノキシジル外用の推奨度A の記載（l.69・82・117・126 付近）を削る」と整理済み。よって `#otc` 内（117・131行）だけでなく、同じページの 69・82 行も対象とする。フィナステリド・デュタステリド（処方薬・販売名なし）の A、ミノキシジル内服の D はそのままでよい。
4. **代替**: 推奨度を残したいなら、価格表を取り下げて前の状態（80行の猶予の範囲）に戻すしかない（案B）。本件の目的（費用感）を優先するなら案A（下の指摘1）を採る。どちらにするかは経営企画が決める。**価格表と推奨度Aの併存は不可**。

解消。オーナー撮影の2枚が `.sources/`（Git 管理外）に保存され、README に記録済み。なお price の png にはブラウザのブックマークバー（個人のフォルダ名等）が写っているので、**リポジトリ（公開）には入れない**こと（現在は `.gitignore` の対象で問題なし）。
