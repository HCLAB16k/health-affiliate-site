## 前工程への質問・異議

1. **国民生活基礎調査の数値は「夜間頻尿」の数値ではない。** 00-brief の「統計（国民生活基礎調査の有訴者率）」と 0041 の記録は正しい。ただし、調査票の項目は「頻尿（尿の出る回数が多い）」で、昼か夜かを区別していない（事実表 #20）。記事で「夜間頻尿の人は千人に50人」とは書けない。夜間頻尿そのものの国内の頻度は、日本排尿機能学会の関係者による全国オンライン調査（JaCS 2023）の数値がある（#21）。**2つの統計を、何を数えたものかを分けて並べる**ことを提案する。
2. **「何回から」の答えは、資料によって言い方が違う。** 編集が1つにまとめないよう、3つに分けて書くことを提案する。
   - 定義: 日本泌尿器科学会の一般向けページは「夜間、排尿のために1回以上起きなければならない症状」としている（#1）。
   - 治療の対象: 前立腺肥大症のガイドラインの修正・追加2023は、「本人または介護者が治療を希望している」ことが必要で、QOL の障害になっていなければ医療上の問題とはならないとしている。そのうえで「一般的には2回以上が治療対象」としている（#9）。
   - 2017年版の文言: 2017年版の本体には「通常夜間排尿回数2回未満は正常とみなされる」という文があった（#10）。2023年版の CQ5 にはこの文が無い。「1回なら正常」とガイドラインを出典にして書くのは避けたほうがよい。
3. **学会のサイトとガイドラインは「転載」が許可制・有料。記事は「引用」の範囲にとどめる必要がある。** 日本泌尿器科学会の Web サイト転載要領と日本排尿機能学会のガイドライン転載要領は、どちらも商用の転載を「図（表）1点または引用文章100字までにつき10万円（税別）」としている（#30・#31）。対象は、学会ページの図（排尿日誌の記入例）、ガイドラインのアルゴリズム図、排尿日誌の様式。これらは**記事に載せず、学会の PDF へのリンクで案内する**ことを提案する。本文で原文を使う場合も、著作権法の引用の範囲（短く、カギかっこで区別し、出典を付ける）にとどめる。範囲の線引きは経営企画で決めてほしい。
4. **ed-otc-tadalafil へのつながりは、書き方を誤ると OTC 医薬品の承認範囲を超えて読める。** 夜間頻尿のガイドラインには、2回以上の夜間頻尿が15年後の勃起障害の強い予測因子だったという記載がある（#13）。JaCS 2023 でも、男性の夜間頻尿と ED の関連が報告されている（#21）。どちらも ED 記事へのリンクの根拠になる。一方、前立腺肥大症の治療薬には PDE5 阻害薬（一般名タダラフィル）も含まれる（#9・#11）。**「前立腺肥大症の薬にタダラフィルがある」という文と ED 記事（要指導医薬品シアリス）へのリンクを近くに置くと、市販品が夜間頻尿にも使えるように読める。** 市販品の効能は ED だけ（0043）。提案は2つ。夜間頻尿の記事では治療薬の一般名を書かない（「薬物療法がある」まで）。ED 記事へのリンクは「夜間頻尿と ED の関連の報告」の段落に置き、治療の段落とは分ける。
5. **loh-testosterone へのつながりは弱い。** LOH 症候群の手引き（0030 の写し）で夜間頻尿に触れているのは、テストステロン補充療法の研究を並べた表の1行だけ（「夜間頻尿に効果あり」、PDF p.72）。この1行から補充療法を夜間頻尿の対策のように書くのは不適切。LOH 記事へのリンクは「泌尿器科では男性更年期の相談もできる」程度の案内にとどめることを提案する。
6. **sleep-support との重複は小さいが、役割を分ける必要がある。** sleep-support はすでに睡眠時無呼吸の受診の目安（`#visit-apnea`）と、睡眠ガイド2023 の嗜好品の記述を扱っている。本記事は「夜中に起きる原因の1つとしての睡眠時無呼吸」と「泌尿器科のガイドラインが睡眠の検査に触れていること」に絞り、受診の目安の詳細は sleep-support にリンクすることを提案する。keywords.csv に、夜間頻尿・トイレ・前立腺・排尿の語は無い（2026-10-13 確認）。

## 要約（3行）

- **定義と目安**: 日本泌尿器科学会は、夜間頻尿を「夜間、排尿のために1回以上起きなければならない症状」としている。前立腺肥大症のガイドライン（修正・追加2023）は、本人が困っていて治療を望むことが前提で、「一般的には2回以上が治療対象」としている。原因は大きく①多尿・夜間多尿 ②膀胱にためられる量の減少（前立腺肥大症・過活動膀胱など）③睡眠障害（睡眠時無呼吸を含む）の3つで、原因の切り分けには排尿日誌が推奨されている。
- **競合の隙**: 上位はメディカルノート・All About・睡眠関連企業のメディア・プレジデントオンラインなど。どれも、ガイドラインの公開版（2024年のアップデート）を出典として示していない。「死亡率2倍」を見出しにする記事もあるが、ガイドラインはこの関係にエビデンスの質の留保を付けている。「何科」は「泌尿器科」の一言で終わる記事が多く、内科が先になる場合の説明が薄い。
- **記事の軸の提案**: 「回数の数え方（定義・困りぐあい・治療の対象）→ 原因の3分類 → 排尿日誌（学会の様式にリンク）→ ガイドラインにある生活の見直し → 何科・急ぐ症状」。統計は「頻尿の有訴者率（国民生活基礎調査）」と「夜間2回以上の割合（JaCS 2023）」を分けて書く。

**競合の弱点（当サイトが埋められる隙）**
1. **2024年のガイドラインのアップデート（公開版）を出典にした一般向けの記事が見当たらない。** 「生活指導」「行動療法」がどの原因に推奨され、推奨度がどうか（例: 多尿・夜間多尿への飲水指導はグレード A、運動療法はグレード B だが RCT の報告はない、禁煙は C1）を書いた記事が無い。
2. **「何回から」に、定義と治療対象の違いで答えた記事が無い。** 「1回以上」と「2回以上」が混ざっている。
3. **統計を取り違えている。** 「頻尿」の有訴者率と夜間頻尿の頻度を区別した記事が無い。
4. **「何科」が一言で終わる。** 泌尿器科が基本である。ただし、ガイドラインは夜間頻尿だけの場合（夜間多尿・睡眠障害が多い）に内科の病気の治療を優先する流れを示しており、その説明が無い（#11）。急ぐべき症状（尿がまったく出ない・発熱を伴う・血尿）の整理も弱い。
5. **不安のあおり**: 死亡率の数値を、留保なしに見出しにしている記事がある。

## 次工程への申し送り

- **構成の提案**（見出しは編集が決める）:
  1. 結論の要約: 定義は1回以上。困っていて治療を望むなら相談の対象で、ガイドラインでは一般的に2回以上が治療対象（#1・#9・#12）。
  2. 夜中に起きる3つの原因（#2〜#4・#11）。
  3. 排尿日誌のつけ方（#5・#9・#24）。日誌の様式は日本排尿機能学会の PDF にリンクする。様式や学会ページの図を記事に転載しない（異議3）。3日間の記録が推奨されていること、1回の尿量の目安（200〜300ml／100ml 以下）が原因の手がかりになること。
  4. ガイドラインにある生活の見直し（#6・#15〜#17・#25）。「寝る前の水で血液サラサラ」には根拠がないこと（#6・#16）。夕方以降のアルコール・カフェイン、塩分。推奨度とエビデンスの限界も添える（運動は RCT なし、統合的指導の RCT では差がなかった等）。
  5. 何科か: 基本は泌尿器科（#8・#29）。夜間だけ多い・昼もトイレが近い・のどが渇くなどの場合は、内科の病気（糖尿病・高血圧・心不全・腎臓病）や睡眠時無呼吸が関わることがあり、かかりつけの内科で相談する流れもある（#3・#11・#19）。いびきや日中の眠気があれば sleep-support の `#visit-apnea` へリンクする。服用中の薬は自己判断でやめず、医師・薬剤師に相談する（#18 は「薬で夜間頻尿が出ることがある」の根拠。特定の薬の名前は出さない）。
