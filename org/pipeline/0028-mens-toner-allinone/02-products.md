## 前工程への質問・異議

1. **（01 の申し送りへの回答）NULL のオールインワンは見送る。** 01 は「NULL のプログラムの対象にオールインワンが含まれるか」の確認を求めていた。
   - A8 の NULL メンズBBクリームのプログラムは、成果対象が「BBクリーム」のみ（owner-inbox D12、2026-09-29 オーナー確認）。オールインワンは対象外。
   - 公式ストアのオールインワンジェルのページ（3,259円）には、区分（化粧品／医薬部外品）、全成分、効能の記載がテキストで見当たらない（`tp_null_allinonegel_20261007.*`。画像だけで示しているとみられる）。そのうえで、商品タグと画像の alt に「ニキビ予防」「しわ」「肌荒れ」が並んでいる。checklist 1章の「区分を最初に確認する」を満たせない。
   - → オーナーが A8 で NULL のオールインワン用の別プログラムを見つけ、容器で区分を確認できるまで載せない。
2. **（04・05 への申し送り）Amazon アソシエイトの価格表示の規定と、論点6（メーカー公式価格を載せる）の関係。** Amazon の運営規約は、価格は Amazon が価格データを付けて提供するリンクか API で取得した場合に限って表示できる、としている。また、Amazon 以外のサイトの価格と「比較」形式で並べる場合は、Amazon の最低価格も表示する必要がある（`.sources/amazon_associate_policies_20260928.txt` 236・239行）。当社がメーカー公式サイトの販売価格を書くのは Amazon の価格の表示ではない。ただし、**Amazon のボタンのすぐ近くに置くと、価格の比較のように読まれるおそれがある**。対策として、枠の中では「メーカー公式サイトの販売価格（◯年◯月◯日確認）」と出所を明記し、Amazon のボタンには「価格はリンク先で確認」とだけ書いて、Amazon の価格は書かないことを提案する。これで足りるかはレビュー部に判断してほしい。tools.html は価格を載せない運用にしている。
3. **（経営企画宛て）運営者の使用品を、他社の広告商品と同じページに並べること。** 適正広告基準の解説は、「私も使っています」のような使用経験の広告を原則として認めていない。例外は、化粧品で使用感を説明する場合などに限られる（01 の事実表、解説 PDF p.21）。また、資生堂メン C 以外の商品を運営者が使った記録は無い（owner-experience.md）。
   - 提案: C の枠には「運営者が自分で購入して使っている（運営者の申告）」という**事実だけ**を書く。感想・評価は書かない（取材で得られても、このページでは使わない）。
   - ページの冒頭には、「運営者が使っているかどうかは、掲載の基準にも並び順にも使っていない」と明記する。
   - **ほかの商品について「運営者は使っていない」とは書かない**。使っていないことはオーナーに確認していないため（書くなら確認が要る）。
   - 05 で形式の事前確認をするとき（00 の論点1）に、この点も一緒に見てもらう。
4. **（00 への補足）「主推奨」の扱い。** 00 の判断では順位を付けないので、この書類の「主推奨」は**社内の設計上の軸**（ページを成り立たせるために欠かせない枠）の意味で使う。記事の中で「主推奨」「イチオシ」等として扱わない。枠の大きさ・ボタンの文言・情報の項目は、全商品で同じにする。
5. **（01 への指摘・軽微）** 01 の「事実確認済みの情報」は、資生堂メン C の価格を「SHISEIDO オフィシャルサイトの販売価格」と正しく書いている。一方で 00 の論点6は「メーカーの公式価格（希望小売価格）」と書いている。**資生堂・バルクオム・ファンケル・HOLO BELL・ZIGEN の公式ページは、どれも「希望小売価格」とは書いていない**（自社の通販の販売価格）。編集部は「希望小売価格」の語を使わず、「◯◯公式サイトの販売価格」と書くこと（価格表示の指針。01 の事実表 PDF p.10〜12）。ルシードの公式ページには価格の表示が無い。

## 決定

- **主推奨（商品）**（＝ページ設計の軸。記事の中で順位や推奨として扱わない。上の異議4）:
  1. **BULK HOMME THE REPAIR LOTION**。読者にとっての理由は次のとおり。①**承認効能の原文が公式に示されている医薬部外品の化粧水**なので、00 で決めた「部外品は承認効能の原文」の枠を、推測なしで埋められる。②単品で買えて、メーカーが使用期間の目安（約1ヶ月）を表示している（論点3の「メーカー表示のときだけ引用」に合う）。③「化粧水＋乳液」を選ぶ読者の実例になる（公式は乳液との併用を推奨）。**条件**: リンク先は単品のページか Amazon（販売元がバルクオム自社か Amazon.co.jp の場合）にする。定期コースの LP にはリンクしない。定期の条件（キャンセル料3,000円・電話連絡・7営業日前）は枠に必ず書く。ASP の成果条件が「定期コースの初回だけ」なら、ASP リンクは使わず Amazon にする（下の (d)）。
  2. **SHISEIDO メン ハイドレーティング ローション C**。読者にとっての理由は次のとおり。①**定期縛りがない**単品の化粧品で、店頭でも買える。②運営者が自分で購入して使っている事実を、捏造なしで書ける唯一の商品（効能・感想は書かない）。報酬は低い（約220円・推定）が、主推奨にしたのは報酬が理由ではない。

### (c) 各商品の事実の枠に入れる項目（全商品で同じ項目・同じ順番・同じ大きさ）
1. 商品名（公式の表記）、メーカー（販売業者。特商法の表記の会社名）
2. 区分: 「医薬部外品」／「化粧品」（公式の表示による。容器で確認できた場合はそう書く）
3. **医薬部外品のみ**: 承認効能の原文（公式の「効能効果」欄の文言をそのまま。縮めない・言い換えない）と有効成分名。化粧品には効能の行を作らない（00 の論点5。56項目の範囲であっても、メーカーの説明文から選んで抜き出すと当社の主張になるため）
4. 内容量
5. 価格: 「◯◯公式サイトの販売価格 ◯円（税込）、2026年◯月◯日確認」。割引率・「通常価格」・「最安」・EC の価格は書かない（論点6）。メーカー価格の表示が無い商品は載せない
6. 使用期間の目安: メーカーが「約◯日分」「約◯ヶ月」と表示している場合だけ原文を引用（BULK「約1ヶ月間」、ファンケル「60mL：約30日分」、ZIGEN「約2.5ヵ月※個人差があります」）。無ければ「メーカーの表示なし」（論点3。資生堂 C は「表示なし」）
7. 使い方・使用量のメーカー表示（例: 資生堂「500円硬貨大」、BULK「10円玉大程度」）。テクスチャーの表示は、使用感の範囲で1行まで（「さっぱり」等）。強調しない
8. **定期便の条件**: 有無／価格の変わり方（初回と2回目以降）／回数の縛り・最低購入単位／解約の期限と方法（電話・マイページ・問い合わせフォーム）／キャンセル料／トライアルからの自動移行。定期が無い商品は「定期便なし（公式ページに記載なし）」
9. リンク先の種類と販売元: 「公式ストアの単品ページ（広告）」「Amazon（広告）。販売元は◯◯（◯月◯日確認）」
10. 運営者の使用: C だけ「運営者が自分で購入して使っている（運営者の申告）」。ほかの商品はこの行を作らない（異議3）
- **入れないもの**: 順位・点数・◎○△・「おすすめ度」、「No.1」「業界初」、購入者レビュー、「浸透」（角質層の注記があっても）、「低刺激」「アレルギーテスト済み」「ノンコメドジェニック」の強調、メーカーの画像・バナー。
- **並び順**: 区分ごと（医薬部外品→化粧品、または化粧水→オールインワン）、その中は五十音順などの機械的な順にする。並び順の基準をページに書く。

### (d) 定期縛りの強い商品の扱い
- **リンク先は単品（通常購入）のページか Amazon・楽天にする。** トライアル・初回特典・定期コースの LP にはリンクしない（HOLO BELL のトライアルは8日後に定期へ自動移行、BULK の定期は2回目の発送前の解約にキャンセル料3,000円）。
- **ASP の成果条件が「定期コースの申込み」だけの案件は、掲載しない。** 単品購入も成果になる案件か、Amazon・楽天のリンクで代える。読者を定期に誘導しないと報酬が出ない構造は、「広告ばかりで信用できない」という読者の不信（01）に直結する。
- **どの商品も、定期便の条件を枠の中に書く**（単品にリンクする場合も、公式で定期を勧められるため）。「お試し」「いつでも解約OK」「全額返金保証」を、メーカーの強調どおりに引用しない（01 の申し送り、特商法ガイドライン PDF p.9）。HOLO BELL の「キャンセル・休止・解約はいつでもノーチャージ」は、「解約は次回お届け日の5営業日前までに、マイページの問い合わせから」という**条件の形**で書く。
- **ZIGEN（2回縛り＋2本セットから）は、単品のリンクが取れない限り載せない。** 載せる場合も「定期は2回目までの継続が条件、2本セット（14,365円）から」を、単品の価格と同じ大きさで書く。
- **前半の「選び方」の節**（商品名なし）で、定期便を確認する点（総額・回数・解約の方法と期限・キャンセル料・トライアルの自動移行）を一般論として説明する（国民生活センターの相談件数は 01 の事実表を出典に）。後半の枠は、その確認点と同じ項目で埋める。

## ポートフォリオへの効果

- **`org/goals.md` の平均単価目標（5,000円）に対する寄与**: **単価を下げる側の案件**。Amazon は5%（公開情報）で1件あたり約180〜220円（推定）。ASP の案件が取れても、類例（A8 の男性向け化粧品: NULL BB 1,000円、HOLO BELL 1,000〜2,500円＝オーナー確認値）から見て1件1,000〜2,500円程度になる見込み（**推定**。本件の候補の実際の報酬は未確認）。目標表の「中単価（1,000〜5,000円）」の下の方、Amazon 分は「低単価」に入る。
- **件数の見込み（推定）**: 公開から3ヶ月程度は、検索流入が月数百PV以下と見込まれる。逆算モデルの率（クリック率7%、成約率1.2%）を当てはめると、月0〜1件程度で、月の収益は数百〜数千円（推定）。月10万円への直接の寄与は小さい。
- **それでも作る理由**: ①D0013 で商品リンクを置けない解説記事（skincare-antiaging・mens-selfcare-start・winter-shaving-skin）の収益の受け皿になる。②「定期 解約」系の不安解消のキーワードは競合が弱い（01）。③既存の HOLO BELL の提携を活かせる。**高単価（クリニック）の件数を増やす本筋の代わりにはならない**ので、ASP の確認・申請は、owner-inbox の優先度で B6・B7（クリニックの審査結果）より後に置く。
