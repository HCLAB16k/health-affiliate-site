## 持ち越し論点の最終判断

### 論点A: 商品ごとの独立した枠を並べる形式は、適正広告基準 第4の9・JCIA F10.2 の「他社製品との比較広告」に当たるか
**判断: 下の条件をすべて満たす限り、形式として可（当社の解釈）。**

- 第4の9 の解説・F10.2① が禁じているのは「製品同士の比較広告」、つまり複数の製品を比べて見せる広告である。各枠が**その製品のメーカー自身の表示だけ**を載せ、枠どうしを参照・対比する記述が無く、評価の語も無く、並び順が機械的な基準によるなら、比べて見せる広告には当たらないと解釈する。小売店のチラシや EC の商品一覧に複数のメーカーの製品が並ぶのと同じ構造である。ただし、アフィリエイトサイトに複数社の化粧品を並べることについての行政の解釈は `.sources` の中に見つかっていない。**この判断は当社の保守的な解釈であり、行政の確認を経たものではない。**
- 「暗示的」な比較は、形式よりも**中身**で生じる。今の原稿で暗示的な比較を生んでいる要素は2つある。①1商品にだけ付いた「運営者の使用」の行（#1）。②前半の確認点5つで「後半の欄も同じ5点で埋めた」と書き、読者に枠ごとの採点を促している書き方（#5）。この2点を直すことを形式可の条件にする。
- F10.2② は、広告に**他社の製品名**を無断で使わないことを求めている。ステマ運用基準（第2の1⑵ア(ｳ)、PDF p.3〜4）により、ASP の枠は各広告主の表示として扱われる。そのため、同じページに他社の製品名が並ぶことへの広告主の了承（02 の O5 ①③）を、**ASP の広告主ごとの公開の必須条件**とする。Amazon・楽天の枠ではメーカーは広告主ではないので、O5 の対象外とする（02 の整理に同意）。この点は残存リスクとして記録する。
- 形式を「可」とする条件（すべて必須）:
  1. 各枠は、その製品のメーカー（またはリンク先の販売者）の表示だけを、出典と確認日つきで載せる。当社の評価や運営者の使用は載せない。
  2. 枠どうしを参照・対比する文を書かない（「こちらは定期便なし」「より安い」「◯◯と違って」等）。合計額・1日あたり・価格の一覧表も作らない。
  3. 全枠で同じ項目・同じ順番・同じ大きさ・同じボタン文言にする。並び順の基準を書き、その基準どおりに並べる（#8）。
  4. 前半は商品名を出さない一般論にとどめ、後半の枠を採点する物差しとして見せない（#5）。
  5. ASP の広告主は O5 の了承を得てからリンクを置く（#10）。
- F10.1 の〔注意〕（既存カテゴリーを比較の対象にすると誹謗につながりやすい）について: title の「化粧水とオールインワン、どっちにする？」は製品の種類どうしの問いである。本文で「どちらが優れているかを示すものではない」と明記し（69行）、優劣を書いていないので許容する。

### 論点B: 運営者の使用品を、広告主の商品と同じページに並べること（02 異議3、04 申し送り6）
**判断: このページでは「運営者の使用」を書かない（必須）。** 適正広告基準の解説 PDF p.21 は、「私も使っています」を使用経験の広告の例として名指しで挙げ、原則不可としている。例外は「化粧品等の広告で使用感を説明する場合」だが、原稿の行（146行）は使用感の説明ではなく、使っている事実だけを書いている。そのうえ、複数社の商品が並ぶページで1商品にだけ付くと、その商品を推す要素として働き、論点A の暗示的な比較にもなる。注記（111行・190行）でこれは打ち消せない。tools.html のように「運営者が使っているものの記録」として全品が同じ条件で並ぶページとは、性質が違う。

### 論点C: tools.html から C の枠（`#item-shiseido-men`）へ直接リンクする案（04 の既存ページ変更文案 ⑤）
**判断: 不可。** 「運営者が使っている化粧水」→ 複数社の広告ページの C の広告枠、という導線になる。これは論点B で外す推薦の要素を、ページの外から付け直すことと同じである。代案は経営企画が選ぶ（#2）。

### 論点D: Amazon アソシエイトの価格表示（02 異議2）
**判断: 原稿の現状（全枠「リンク先でご確認ください」）は可。** 差し替え文案 A（BULK の公式ストアの販売価格）は、**BULK の枠のリンク先が公式ストアの単品ページ（ASP）で、その枠に Amazon のボタンが無い場合に限り**可。当社は Amazon の価格を一切表示しないので、規約の「比較形式」の条項（239行）にはかからない。ただし次の2点を守る。①Amazon リンクの枠には、どのサイトの価格も書かない（資生堂 C の公式価格 4,400円を C の枠に書くと、Amazon の商品の価格についての不正確な主張に読まれうる。規約 236行）。②価格のある枠と無い枠が混ざる理由を `#criteria` に1文書く（#9）。
