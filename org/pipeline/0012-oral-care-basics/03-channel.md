## 決定

- **主媒体・形式**: 自サイトの新規記事（解説ガイド型。比較記事・ランキングにはしない）。新カテゴリ「オーラルケア」の最初の記事。
- **ファイル名（slug）**: `articles/oral-care-basics.html`（案件フォルダ・backlog #25 と同名。サムネイルは `images/thumbs/oral-care-basics.svg`）
- **狙うメインキーワード / サブキーワード**:
  - メイン: **口臭 対策 男性**（入口。題名では「口臭ケア」で受ける）
  - サブ（1記事で受ける）: 口臭 原因 舌苔／舌磨き やり方／フロス 臭い／口臭 何科／口臭 自分で わかる
  - ロングテール（日米差の節で拾う）: 舌磨き しないほうがいい／舌ブラシ アメリカ／マウスウォッシュ 使わないほうがいい（歯磨き後 タイミング）
  - **狙わない**: 「おすすめ」「ランキング」「電動歯ブラシ 比較」「マウスウォッシュ 効果」の商品比較系（強い競合。C02・#27 に回す）、「ホワイトニング」（#11）
- **題名の方向（編集部が確定）**: 「口臭ケアの基本：舌の清掃・フロス・洗口液・電動歯ブラシ、日本と米英の見解の違い」程度。「最強」「効果絶大」「対策」「予防」は使わない。
- **形式を選んだ理由**（検索意図と結びつけて）:
  1. 狙う語の意図は情報収集・不安解消（「なぜ臭う」「舌磨きはしていいのか」「何科に行くか」）。商品比較ではなく解説ガイドが合う。
  2. 競合の隙（公的出典なし、日米の見解差・根拠の強さ・道具の法的区分・受診の目安に触れない）は、解説ガイドでしか埋められない。ランキングで戦うと、my-best・歯科医院・EC に負け、しかも本方針（ランキングにしない）と合わない。
  3. **リライトではなく新規**にする理由: 既存8記事にオーラルケアの記述は無い（`articles/` を検索して、歯科医業の出典1件のみ）。強化すべき既存記事が存在しない。カニバリも起きない（01 の異議7）。
  4. 記事の役割の線引き（カニバリ防止）: 0012＝口臭ケアの基本（何を・なぜ・どの順で）、C02＝歯磨き粉のフッ素濃度（0012 はフッ素に触れるのは NHS の洗口液のタイミングの1点のみ）、#11＝ホワイトニング（0012 では扱わない）、#27＝セール時の商品情報（0012 に価格・セール表現を入れない）。
- **カテゴリ**（`scripts/site_data.json` の `categories` に追加）:
  - `id`: `oral` ／ `name`: オーラルケア ／ `label`: ORAL
  - `lead` 案: 「歯みがき・舌の清掃・歯間清掃・洗口液など、毎日の口のケアで使う道具と考え方を、公的機関や学会の資料で整理した記事です。」
    - 病気・症状・効果の語（口臭を防ぐ、歯周病予防 等）を入れていない。他カテゴリの `lead`（「〜を整理した記事です」型）と文型を揃えた。meta description に入る点を確認済み。
  - 位置: 既存4カテゴリの末尾（`rest` の後）。カテゴリバーは build_site が全ページに反映する。
- **記事エントリ案**（`articles` へ）: `slug: oral-care-basics` / `category: oral` / `date`: 公開日 / `title`: 「口臭ケアの基本」 / `tag`: `ORAL / JAPAN, UK &amp; US` / `desc` 案: 「舌の清掃・フロス・洗口液・電動歯ブラシ。日本・英国・米国の公的機関の見解の違いと根拠の強さを整理」（効能・効果の語なし）。
- **初版の pr-badge**: リンクが無いので、他のリンク無し記事と同じ「PR / 当サイトはアフィリエイト広告を利用しています」（backlog #18 の揃え方）。リンクを追加する版で「本記事は〜含みます」に変える（02 の広告主レギュレーション）。

## 計測

**前提**: GA4 は未導入（goals の現在地）。Search Console は登録・サイトマップ送信済み（owner-inbox A5・履歴）。次の指標は Search Console と ASP・リポジトリで見られる範囲に絞る。

- **Search Console（ページ）**: `articles/oral-care-basics.html` と `category/oral.html` の表示回数・クリック・平均掲載順位。
  - 公開から **2週間後**: インデックス登録されたか（URL 検査。未登録ならサイトマップの取得状況）。
  - 公開から **1〜2か月後**: 表示回数が付き始めるか（SEO は3〜6か月かかるのが通常で、保証はない）。
  - **3か月後**: 平均掲載順位とクリック率で、タイトル・見出しの見直し（リライト案件）を判断。
- **Search Console（クエリ）**: 主キーワード「口臭 対策 男性」「口臭 ケア 男性」、サブの「舌磨き やり方」「舌苔」「フロス 臭い」「口臭 何科」、ロングテールの「舌磨き しないほうがいい」「舌ブラシ アメリカ」「マウスウォッシュ 使わないほうがいい」。どの語で表示されているかで、狙いと実際の流入のずれを見る。**「おすすめ」「ランキング」系の語で表示されるようなら、C02・#27 の入口が要るサイン**。
- **X（告知の効果）**: X 投稿の日付の前後で、Search Console の同記事のクリック・表示が増えたか（直接の流入元は GA4 が無いため見られない）。X の管理画面でインプレッション・リンクのクリックをオーナー確認できる場合のみ参考にする（オーナーに手間を頼まない。月初の E1 とまとめて回答があれば可）。
- **ASP の指標**: 初版はリンクなしなので**見ない**（クリック・発生は0の想定）。リンク追加版の公開後に、Amazon アソシエイトのクリック数・注文数、もしも・A8 のクリック・発生・確定を月次（分析部）で確認。1件が数十〜数百円（推定）なので、成果は「件数」で見る。
- **サイト内の送客**: GA4 が無い間は、記事内リンクの効果を測れない。オーナーの C1（GA4 導入）の回答が出たら、oral-care-basics から retinoids・skincare・（公開後の）#11 へのクリックを見る。
- **カテゴリの指標**: `category/oral.html` の表示回数（新カテゴリのハブとして育つか）。記事が2本以上になってから見る。

## 保留した施策と理由

- **note・Instagram・Pinterest への展開**: 月10万円（平均単価を上げる高単価案件）に直結しない。オーナーの投稿・画像作成の手間が大きい。口臭・口のケアは画像映えする題材でもなく、根拠の強さを示す記事の差別化とも合わない。**保留**。再開の条件: 高単価案件の記事が育ち、被リンクが必要と分析部が判断したとき。
- **Yahoo!知恵袋・掲示板・Q&A への回答による誘導**: 自作自演・宣伝と受け取られるリスクがあり、ステマ規制（checklist 3章）の観点でも不適切。実施しない。
- **既存記事への逆リンクの追記（今回）**: 上のとおり、再審査の負担に対し効果が小さい。#20・#21 のリライト時に併せて行う。
- **「口臭チェッカー」「口臭 何科 診断」のような診断風ツール・別ページ**: 医療広告・診断の領域に踏み込む。00 のスコープ外。実施しない。
- **商品比較ページ（電動歯ブラシ・舌ブラシ・マウスウォッシュのおすすめ）**: 競合が強く（my-best・EC・歯科医院）、報酬も低い（推定）。C02・#27 で商品を絞って扱う。**保留**。
- **11月8日「いい歯の日」に合わせた特集**: 日付と主催の一次情報が未確認。確認できたら X の2回目の告知（任意）にとどめ、専用ページは作らない。
