## 持ち越し論点の最終判断

1. **EMA の URL に販売名が含まれる件（04 質問1）→ 残してよい。** 参考資料の URL はリンクにしないテキストで、本文に販売名はなく、購入・受診への導線もない。医薬品等の広告の3要件（①誘引性 ②特定の商品名 ③一般人が認知できる状態）のうち①を欠き、薬機法68条の「承認前の医薬品の…広告」には当たらないと判断する。代わりの URL（EU の Union Register など）にしても、出典としての確かさが下がるだけで、承認取得者名と「2mg 徐放錠・55歳以上」から製品は特定できるので、効果は小さい。ただし記事は l.60・l.203 で「処方薬は一般名だけで書いています」と言い切っており、URL の字面と食い違う。文言の調整を推奨する（指摘 #6）。製品番号（EMEA/H/C/000695）を併記すると、URL が変わっても辿れる（任意）。
2. **「時差ぼけは日本の承認効能に含まれない」の1文（04 質問2）→ 残してよい。** 電子添文の効能（l.196〜197）からそのまま言える事実で、NCCIH の「may help」を受けて、日本の医薬品としては時差ぼけの効能が認められていないことを示し、効能の暗示を打ち消す方向に働く。成人への処方・医療機関・費用には触れていない。比較表 l.143 の「承認された効能に含まれていない」も同じ扱いで可。
3. **禁忌の薬を1つだけ書く件（04 質問3）→ 書いてよい。ただし網羅していないことを明示する（指摘 #5、推奨）。** 一般名のみで、出典は東京都の公表文（原文「フルボキサミンマレイン酸塩（うつ病などの治療薬として処方される）を服用している方には禁忌とされており」と一致）。販売名なし。00 判断⑦の対象（カフェインの併用注意）にも触れていない。
4. **子どもの誤飲の数値（04 質問4）→ 現状は「抜き出し」に当たる。必須の修正（指摘 #1）。**
5. **時差ぼけの両論の書き方 → 可。** 当社の文で効果を言い切っておらず（l.148「当社として…判断するものではありません」）、NCCIH の根拠の年（2010・2014）と NHS の見直し期限超過の注記がある。要点 l.69 でも両論が1文に入っている。時差ぼけの節と個人輸入の節の間に「薬を使わない対策」（l.157〜166）が挟まっており、「役立つ可能性がある」から入手の話へ直接つながる構成にもなっていない。
6. **個人輸入の書き方 → 入手方法の案内には当たらない。** 数量・手続き・通販・代行業者なし、厚労省の原文（`mt_mhlw_kojinyunyu_index` l.223〜244・277、`tp010401-1` l.219）どおりのリスクの列挙。導入 l.169 も「この記事では、数量の目安や手続きは扱いません」と明記。
