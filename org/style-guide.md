# 文体ガイド（男の養生帖）

- 制定: 2026-10-09（案件0036。オーナー「コンセプトは良いが、文章が硬くて読みづらい」）
- 根拠: 人気サイト11サイトの実測（`org/pipeline/0036-readability-seo/01-research.md`）と、レビュー部の線引き（同 `05-style-rules.md`）
- 対象: 新しい記事すべてと、既存記事の読みやすさのリライト。**法令・掲載基準の線は `org/compliance-checklist.md` が優先**。迷ったら言わない側。

## 0. 原則（ひとことで）

**中身（主体・対象・条件・留保・数値・出典）はそのまま、形だけを軽くする。**
読者は「調べもの」をしに来た忙しい人。先に答え、短く区切り、言葉をやさしくする。

## 1. 数値の目安（上限ではなく目安の幅）

| 項目 | 目安 | 当社の現状（0036 実測） |
|---|---|---|
| 1文の長さ | **中央値 30〜40字**（機関名・資料名が長い当社の記事の現実的な幅。人気サイトは22〜37字）。60字を超える文は1割未満。「」の原文の引用は `<blockquote>` に出して数えない | 37〜50字、23〜34% |
| 1段落 | **2〜3文、50〜120字** | 114〜147字 |
| リード（h1 の下） | **1段落・100〜150字**。読者の疑問 → この記事で分かること | 3段落・420〜480字 |
| 「先に要点」の1項目 | **1〜2文（60字前後）**。詳細は本文・表へ | 最長233字 |
| 本文中の［n］ | 段落の最後に1回が基本（下の4章） | 1000字あたり6〜9.5個 |

## 2. 組み立て

1. **結論を先に。** 各節の最初の1文で、その見出しの問いに答える（「資料にはこう書かれている」「資料が無い」も答え）。理由・条件・例外はその後。
2. **1文1要素。** 「〜で、〜し、〜なので、〜としています」とつなげない。2〜3文に切る。
3. **並ぶものは箇条書きか表に。** 3つ以上の手順・条件・機関の比較は、文にせず箇条・表にする。
4. **段落に手順を詰めない。** 手順は番号つきの箇条書き。
5. **まとめ**は3〜5項目の箇条。新しい事実を足さない。

## 3. 見出し

- **読者の疑問の形でよい**（疑問形も可）。例: 「カフェインは1日どれくらいまで？」「何科に行けばいい？」
  - 条件: 見出しのすぐ下の1文で答える。
  - NG: 効能を問う見出し（「〜で治る？」「ぐっすり眠れる？」）、恐怖・焦り（「放置すると」「手遅れ」）。
- 「X：Y」型（資料の整理の軸）は、必要なときだけ。h2 は読者の言葉、h3 で機関名・資料名を出す、が基本。
- 見出しの数: h2 は 5〜9 個。目次は build が自動で付ける（h2 が3つ以上）。

## 4. 出典と「誰が言ったか」の見せ方（レビュー部の線引きどおり）

- **誰の見解かが文から読めることが必須**。文末の「〜としています」は必須ではない。
  - 文頭に出す: 「厚労省の睡眠ガイドによると、〜です［11, p.32］。」
  - 同じ機関の説明が続くときは、同じ段落で間に別の機関・当社の意見が入らない限り、2文目から主語を省いてよい（留保は残す）。
  - 当社の整理・当てはめには目印（「つまり」「当社が当てはめると」）。複数の機関を1文に混ぜない。
- **［n］の置き場所**: 段落が同じ出典だけなら段落の最後に1回。まとめ方は［1, 3, 4］、ページは［11, p.32］。
  - 文ごとに付けるもの: 出典が混ざる段落、数値のある文。
  - 本文のその場に置くもの: 価格・内容量・定期購入の条件の確認日、企業所属の著者・研究の資金（参考資料にも）。
- 「」で囲む原文（届出表示・承認効能・ガイドラインの推奨文・行政の回答）は言い換えない。

## 5. 言葉

- **専門用語は「やさしい言葉（用語）」の順**。例: 「1日に取っても健康への影響がないとされる量（ADI：一日摂取許容量）は推定値で〜」
  - 言い換えは「何であるか」まで。働きの動詞（守る・整える・促す・改善する）や評価語を足さない。NG: 「肌のバリアを守る油分」「安全な量」「浸透」「肌の奥まで」。
- 「です・ます」。語りかけ・共感は可（「気になりますよね」程度）。体験談に見える書き出し、「（30代・会社員）」のような属性ラベル、猫に語らせることは不可。
- 漢字を開く目安: 「〜する事→こと」「〜の為→ため」「出来る→できる」「様々→さまざま」「殆ど→ほとんど」「下さい→ください」「頂く→いただく（補助動詞）」。
- 否定・念押しは同じ趣旨を1回にまとめる。ただし次は必ず残す: 運営者の使用品の「効果を示すものではない」・自費購入の申告、医薬部外品の効能を載せない理由、表の「順位ではない」と並び順の基準、「当サイトは個人輸入を勧めません」、末尾の disclaimer、資料が無いことの明示。効果を否定で言い切る文（「効果はありません」）は断定なので NG。

## 6. ページの型

```
pr-badge（動かさない）
h1
（byline：build が自動で入れる）
リード 1段落（読者の疑問 → この記事で分かること）
  ※ リンクのある記事は「リンクの数と場所」の1文をここに（冒頭必須）
先に要点（3〜5項目、各1〜2文）
（目次：build が自動）
h2 …（各節は結論の1文から）
まとめ（3〜5項目）
この記事の作り方（下の箱。全記事で同じ見出し・同じ順）
関連記事
参考資料（出典と確認日）
（同じカテゴリの記事：build が自動）
disclaimer
```

**「この記事の作り方」の箱**（見出しは固定: `<h2 id="method">この記事の作り方</h2>`、順番も固定）
1. 本文の［n］は参考資料の番号、確認日（参考資料の一覧と同じ日付）
2. 記事の範囲（扱わないこと）
3. 利益相反・資金の案内（ある場合）
4. 商品・医療機関の扱い（リンクの有無）。**リンクを後から足すときは、冒頭の1文とこの箱の2か所を一緒に直す**

## 7. 要点・meta description・SNS

- 要点・見出し・meta description・X の告知でも、主体・対象（「健康な成人」「妊娠中を除く」等）・条件・留保・副作用の条件・症例の例外は落とさない。
- title: 全角32〜40字を目安。主キーワードを前半に。煽り・最大級・効能の言い切りは使わない。
- meta description: 80〜110字。記事で分かることを具体的に（機関名・数値の有無）。末尾の「商品の紹介なし」等は残してよい。

## 8. リライトの進め方（既存記事）

**パイロットの教訓（0036、2026-10-09）**: 文を切ったり主語を文頭に移したりするときに、帰属（どの機関の文か）と条件（「1日の合計」「事業者向け」等）が付け替わる・落ちる誤りが出た。切った後の各文について「この主語は出典のどの文か」「条件は残っているか」を確かめる。作り方の箱の文言は、本文で実際にしたことと合わせる。

- 1バッチ3〜4本。編集部が書き換え、04 か案件の書類に Before/After の主な文を残す。
- レビュー部が差分審査: ［n］の集合が変わっていないか、留保の語（目安・可能性・推定・といわれています・個人差）が減っていないか、NG 語が増えていないか、必須の文が残っているか（`05-style-rules.md` 末尾）。
- 事実・数値・出典を変えないリライトでも、本文を変えたら site_data の `updated` を更新する。
