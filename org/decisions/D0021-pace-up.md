# D0021 公開ペースを週3本（新規2＋更新1）に上げる（D0016 の改訂、4週間の試行）

- 日付: 2026-10-29
- 決定者: 経営企画（オーナーの「ペースを上げられるか」の相談を受けて。判断は任せると事前に委任あり）
- 関連: D0016、D0020、案件0050（週次トレンド）、`org/kpi/`

## 背景（2026-10-29 時点）
- 公開30本。Search Console 3か月で表示234・クリック0、インデックスは約12ページ。表示の大半はアシュワガンダ記事1本から（1本の記事が多くの検索語の入口になる）。
- 書く・レビューする能力に余裕はある。制約は (a) Google がこの新しいサイトを読み込む速さ、(b) リンクの承認待ち、(c) 品質（YMYL）。

## 決定（2026-10-29〜11-26 の4週間の試行）
1. **週3本**: 火曜に新記事1本（backlog から。収益の受け皿になる比較・選び方のテーマを優先）、木曜に週次トレンドで1本（新規または更新）、ほかに既存記事の更新1本（確認日の古い数値、Search Console で表示はあるがクリックが無い記事のタイトル改善）。
2. レビュー PASS 前の公開はしない（D0006）。品質の基準・コンプライアンスは変えない。量のために一次情報の確認・［n］を省かない。
3. **やめる・戻す条件**（どれか1つで週1〜2本に戻す）
   - レビューで BLOCK が出る、または REVISE が2週続けて2回以上
   - 4週間後に、新しい記事の表示回数が増えていない（インデックスが追いついていない）
   - 利用上限に当たり、月曜の KPI・木曜のトレンドの定期実行が回らない
4. 同じ検索語を取り合う記事（カニバリ）を作らない。新記事の前に既存記事と重ならないかを researcher が確認する。

## 理由
- 記事が増えるほど検索の入口（ロングテール）が増える。ただし新しいサイトはインデックスが遅く、Google は「検索順位のための大量の自動生成コンテンツ」をスパムと扱うため、量だけを上げると逆効果になりうる。
- 最初の収益に一番近いのは記事の本数ではなく、購入意図のある比較ページ（化粧水 0028・ジム 0047・forteca 0039）にリンクが付くこと。そのためペースを上げる分も収益の受け皿を優先する。
