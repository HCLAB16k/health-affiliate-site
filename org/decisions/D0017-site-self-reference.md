# D0017 記事の中の自称を「当サイト」に統一する（「当社」「私」は使わない）

- 日付: 2026-10-09
- 決定者: 経営企画（オーナーから一任。オーナー「当サイトもありか。任せる」）
- 関連: `org/style-guide.md` 4章・5章、byline（build が入れる「男の養生帖 編集部」）

## 背景
記事の本文で「当社の整理」「当社が確認した範囲」「当社計算」など、「当社」を使っていた。社内の書類で会社に見立てて運営している名残り。読者から見ると、個人運営のサイトなのに会社を名乗っているように読める（オーナーの指摘）。

## 決定
1. 読者向けのページ（articles/・tools.html・site_data の文言・X の告知）では、自称を **「当サイト」** にする。例: 「当サイトの整理」「当サイトが確認した範囲」「当サイト計算」「当サイト訳」。
2. **「私」は使わない**。理由は次の3つ。
   - byline は「男の養生帖 編集部」。
   - 一人称は、医薬品・化粧品の近くで「私も使っています」型の推せん（適正広告基準の解説 p.21）や体験談と読まれやすい。
   - 運営者の使用品は tools.html で「運営者」として別に扱っている。
3. 出典の原文に含まれる「当社」（例: ウエルテックの文書名）は、引用なので変えない。
4. 社内の書類（org/）の「当社」は、そのままでよい。

## 実施
2026-10-09、197か所を置き換えた。文長への影響は小さい（60字超の割合が1割以上の記事は、置き換えの前から同じ値）。
