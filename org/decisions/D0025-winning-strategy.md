# D0025 戦略指針（勝ち筋）: 疑問系の記事で集め、中立の比較ページへ送り、比較ページで稼ぐ

- 日付: 2026-10-30
- 決定者: オーナー（「勝ち筋の仮定を定めたなら、それを実現するのに全部署が向かうべき」）、起案は経営企画
- 関連: D0002（高単価ポートフォリオ）、D0013、D0020、D0021、D0024、`org/goals.md`

## 勝ち筋（仮説）
1. **集客**: 上位が弱い疑問・不安系の検索（「なぜ」「本当に」「副作用」「違法」「日本で買えない」）を、一次資料と海外比較で取る。ニュース直後の解説と、出回る誤情報の検証も含む。
2. **送客**: 疑問系の記事から、同じテーマの**当サイトの中立な比較ページ**へ内部リンクで送る（解説記事に商品リンクを置かない D0013 と両立する）。
3. **収益**: 比較ページは、大手の比較・ランキング型が手薄な**ロングテールの選び方の検索**（例:「メンズ 化粧水 医薬部外品 違い」「パーソナルジム 40代 料金 比較」）を狙う。順位付けはせず、条件・表示・費用・解約の比較で選べるようにし、アフィリエイトリンクは比較ページに置く。

## 現状とのずれ（2026-10-30 時点）
- 比較ページは **0本**（化粧水 0028・ジム 0047 とも、オーナーのリンク確認待ちで止まっている）。直近2週間の作業はほぼ集客側（要点の書き直し・新記事・X）だった。
- 比較ページへの内部リンクも当然 0。

## 決定
1. **比較ページはリンクより先に公開する**。中立の比較そのものに検索の価値があるので、アフィリエイトリンクが揃うのを待たない。リンクは承認が下りた時点で足す（その時点で再審査）。0028 の「リンクが無いと公開できない」という運用を改める。
2. **優先順位**: 当面の新記事・更新の枠は、①比較ページ（0028 化粧水、0047 ジム、次にヒゲ脱毛・AGA の選び方）②比較ページへ送る疑問系の記事 ③それ以外、の順。
3. **すべての案件に「勝ち筋での役割」を書く**（00-brief の必須欄）: 集客／送客／収益のどれか、送客先の比較ページ、狙う検索語。役割が書けない案件は優先度を下げる。
4. **部署ごとの向き先**（`org/departments/README.md` に表）:
   - リサーチ部・分析部: 集客の語と比較ページの語を探す（競合分析の4条件の「収益ページへつながる」を必須に）。
   - 商品企画部・収益・提携部: 比較ページごとに載せる候補と ASP 案件を揃え、承認待ちを追う。
   - 編集部: 疑問系の記事の該当節から比較ページへの内部リンクを入れる。比較ページは順位付けしない形で書く。
   - レビュー部・事実確認部: 比較ページの中立性（推せん条項・ステマ・景表法）を重点で見る。
   - 保守部: 比較ページの価格・条件・リンクを優先して点検する。
   - マーケティング部: X は比較ページと、そこへ送る記事を優先して告知する。
5. **KPI に送客の指標を足す**（`org/goals.md`）: 比較ページ数、比較ページへ内部リンクする記事数、比較ページの検索表示・クリック。
6. **見直し**: 2026-12末に、比較ページの表示・クリックで仮説を検証する。比較ページが検索に載らなければ、狙う語の見直しか、集客記事の中に比較の節を置く形に切り替える。
