# D0023 X の投稿の改善は経営企画の判断で進めてよい

- 日付: 2026-10-30
- 決定者: オーナー（「以後、聞かずに自分で判断してやってみて」）
- 関連: D0010、`org/social/x-style-guide.md`、案件0053

## 決定
1. X の投稿の型・言い回し・構成・投稿時間・形式（返信にリンクを置く、スレッド等）の改善は、オーナーに確認せず経営企画が判断して実装してよい。
2. ただし次は変えない: レビュー部の審査を通った投稿だけを予約する、checklist・D0010 のルール（#PR の位置、煽り・効能の言い切り・体験の捏造の禁止）、API キーは GitHub Actions secrets のみ。
3. 費用が発生する変更（X API の有料プラン、広告）と、アカウントの設定（ラベル・プロフィール）はオーナーに確認する。
4. 結果はオーナーに短く報告する。
