# D0005: 記事テーマのポートフォリオ運用ルール（海外差テーマ・クリニック系・収益化しないテーマ）

- 日付: 2026-09-27
- ステータス: 採用（夜間の経営企画判断、2026-09-28 オーナー確認済み）
- 決定者: 経営企画
- 関連: `org/pipeline/candidates.md`（リサーチ部のテーマスカウティング）、D0002、D0003

## 背景
オーナー方針「海外で標準・トレンドが日本と違うものにも目を向け、更新頻度を保てるよう候補をストックする」を受け、
リサーチ部が19件の候補を出した。医療広告の対象になる導線を含む候補や、国内学会の見解と衝突する候補が含まれる。

## 決定
1. **海外差テーマは「海外ではこう、日本の承認・推奨状況はこう」の比較・解説に徹する。** 日本で未承認・処方薬の成分を購入・個人輸入に誘導しない。
2. **クリニック系（医療広告の対象になる導線を含む）テーマは同時に1本まで。** 公開・レビュー完了を待って次に進む（レビュー負荷と法的リスクの集中を避ける）。
3. **海外の評価を紹介する記事（例: ミノキシジル内服）からは、クリニックへ直接リンクしない。** 必要なら 0001 記事へ送る。
4. **GLP-1ダイエット（candidates C07）は収益化しない。** 日本糖尿病学会の見解と衝突するため。扱う場合も注意喚起の解説のみとし、アフィリエイトリンクを置かない。
5. backlog #3（ヒゲ脱毛）は暫定採用（オーナー確認待ち）。

## 理由
- 当社の強みは「商品区分（日本では医薬品か食品か化粧品か）の違い」を中立に説明できる点で、海外差テーマはこれと一致する。
- 高単価のクリニック導線は収益の柱（D0002）だが、法的リスクが最も高いため、量より確実性を優先する。

## 見直す条件
- クリニック系記事のレビューで REVISE が続かなくなり、運用が安定した場合（同時2本に緩和を検討）
- 国内学会・厚労省の見解が変わった場合（C07 等）
