# D0007: 執筆途中の案件がブランチにある間、PRは下書きにする

- 日付: 2026-09-27
- ステータス: 採用
- 決定者: 経営企画
- 関連: PR #2（0002・0004 が PASS、0003 が執筆途中の状態で同じブランチに同居した）

## 背景
作業ブランチは1本で、複数の案件の変更が同じ PR に入る。途中経過もコミット・push する運用のため、
レビュー前の記事HTMLが PR に入り、その時点でマージされると未完成の記事が公開されるおそれがあった。

## 決定
- 記事HTML（`articles/`・`index.html`・`disclosure.html` 等、公開される文書）に**レビュー PASS 前の変更**がブランチ上にある間は、PR を**下書き**にし、タイトルに【作業中・まだマージしない】と付ける。
- ブランチ上のすべての案件がレビュー PASS（または変更なし）になったら、下書きを解除し、PR説明を案件ごとに書き直す。

## 見直す条件
- 案件ごとにブランチを分けられるようになった場合
