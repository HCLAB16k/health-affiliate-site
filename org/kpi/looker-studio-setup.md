# Looker Studio で週次レポートをメール配信する手順（オーナー作業・初回だけ約10〜15分）

目的: GA4 と Search Console の数字を、毎週メールで受け取る。経営企画・分析部は Gmail のコネクタからそのメールを読み、`org/kpi/` に転記して分析する。

## 1. レポートを作る
1. https://lookerstudio.google.com を、GA4 と同じ Google アカウントで開く。
2. 左上の「作成」→「レポート」。
3. 「データのレポートへの追加」で「Google アナリティクス」を選び、プロパティ（男の養生帖、測定 ID G-K66FGCJ14H）を選んで「追加」。
4. 最初に表ができたら、右側のパネルで次のとおり設定する。
   - ディメンション: 「ページタイトル」（またはページパス）
   - 指標: 「表示回数」「アクティブユーザー数」
   - 並べ替え: 表示回数の降順
   - 行数: 30
5. 「グラフを追加」→「表」で、2つ目の表を作る。
   - ディメンション: 「セッションのデフォルト チャネル グループ」（流入元: Organic Search・Organic Social・Direct など）
   - 指標: 「セッション」
6. （任意）「データを追加」→「Search Console」→ サイト（URL プレフィックス）→「サイトのインプレッション」を選び、3つ目の表を作る。
   - ディメンション: 「Landing Page」
   - 指標: 「Impressions」「Clicks」
7. 上部の「期間」コントロールを追加し、既定を「過去7日間」にする。表は数字が読めるよう、グラフではなく「表」のままにする。
8. レポートの名前を「男の養生帖 週次レポート」にする。

## 2. メールの定期配信を設定する
1. 右上の「共有」の横の ▼ →「配信のスケジュール設定」。
2. 宛先: 自分の Gmail（このセッションが読める Gmail アカウント）。
3. 開始日時: 毎週月曜 8:00、繰り返し「毎週」。
4. 件名: 「男の養生帖 週次レポート」（経営企画はこの件名で検索する。変えないでください）。
5. 「保存」。初回は「今すぐ送信」で試すと確認が早い。

## 3. 経営企画への連絡
- 設定が終わったら「Looker Studio 設定した」とだけ連絡する。経営企画が Gmail で件名を検索し、数字が読めるか確かめる。
- メールの本文・添付 PDF から数字が読めない場合は、配信の形式（PDF の添付）を変えるか、スクショでの共有に戻す。

## 注意
- レポートは非公開のまま（共有リンクを公開しない）。メールの中身はリポジトリ（公開）に転記するとき、オーナーが決めた粒度に留める（収益額は書かない）。
- GA4 の数字は、ブロッカー等で計測されない閲覧があるため、実際より少なめに出る。
