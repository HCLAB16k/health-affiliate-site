## 0. 考え方（ひとことで）

**1行目で何か1つを名指しし（数字・誤解・場面・用語・国の違い・対象者・疑問）、本文だけで「へえ」となる一点を渡し切る。誰が言ったかを添え、残りは記事で。**

- 版1の後、予約投稿14件中13件の1行目が「？」で終わり、リンク投稿10件中6件が「〜も。」で終わっていた（01 D）。版1の「疑問から書き始める」が、実際には「疑問」1択として運用されていた。
- 反応の多い健康系の投稿41件では、冒頭40字以内に「？」があるのは1件だけ。多いのは【見出し】（12件）、誤解を名指しして正す（約7件）、場面・会話、データ1つ、用語の翻訳（01 キーワード表）。**型の傾向を見る資料で、効果の証拠ではない**（フォロワー数の影響と切り分けられない）。
- X の公開コードは 2026-10 に「滞在時間」「最後まで読まれる投稿」を重く見る方向に更新された（01 A）。本文で答えの一点まで読ませる形と向きが合う。リンクを減点する重みは公開コードに無い。
- 中立の立場は変えない。恐怖・誤情報・煽りで止めない（版1の0章と同じ）。

## 1. 基本の形

```
（#PR ）1行目: 型ごとの1行目（2章）。全角 15〜40 字ほど
2行目以降: 答えの一点。事実1〜2つ ＋（誰が言ったか）。型によって箇条・□・国ごとの行
（任意）記事で分かること。「〜も。」は 3章の上限内で
最後の行: 記事URL（リンク投稿のみ。単独の行）
```

| 項目 | 目安 | 理由・出典 |
|---|---|---|
| 1行目 | 2章の型の1行目の形から選ぶ。資料名や「〜の記事を書きました」から始めない | 01 キーワード表・D |
| 本文の長さ | 重み付き 200〜250 を目安（上限は x_post.py の 280。250 を超えたら削る） | 01 の集計で反応の多い投稿の長さの中央値は 147 字。上限ぎりぎりは削る余地がない |
| 改行 | 2〜6か所。箇条・□は1項目1行。空行は入れない | 改行は重み1 |
| 機関名・資料名 | 1投稿に **2つまでが目安**。答えに要る機関だけ。**1つで足りるなら1つ**。見解の違う機関を1つの主語にまとめない（checklist 6章・style-guide 4章）。国の比較（型G）で3つ要る場合は可 | 版1と同じ。01 申し送り1 |
| 数字 | 1投稿に1〜2個。数字のそばに出典・対象・条件 | 記事にある数字だけ（style-guide 7章） |
| URL | リンク投稿は最後の行に記事URLを1つ。fact 投稿は URL なし | x_post.py の要件 |
| #PR | アフィリエイトリンクが描画される記事・ページの告知は、1行目の先頭に「#PR」。描画されない記事には付けない（D0010。A8 の自動置換を ON にしたときは見直す）。型H の【】より前に置く | 消費者庁の運用基準（版1と同じ） |
| ハッシュタグ | #PR 以外は付けない | X の開発者ガイドライン（トレンド操作） |
| 絵文字・記号 | 絵文字・⚠ は使わない。使ってよい記号は「・」（箇条）、「□」（型J）、「【】」（型H）、「＝」（型D）、「：」（型G）、「Q.」「A.」（型I）だけ | 中立の印象。絵文字は重み2 |
| 文末 | 「整理しました」で終えない。「〜とされています。」は、同じ文か直前の文で機関名が分かるときだけ | 版1と同じ |

## 2. 型の一覧（版1の型1〜8 と新しい型を統合）

- ID は queue の JSON の `"type"` に書く（6章）。版1の型との対応は付録。
- 良い例は 01 の申し送り3（記事の該当行を開いて作成）と版1の例。**予約に使う前に、その時点の記事本文で事実を確かめ直す**。長さは 01 の計算（リンク投稿は URL を含む）。
- 「向く記事」は目安。1つの記事に複数の型が使える。

### A 数字1つの大見出し（版1 型3 を統合）
- 1行目の形: 数字で始める、または数字で終わる短い一文（「〜の男性、27.1%。」）。
- 構成: 1行目に数字 → 2行目で「誰の・どんな調査の数字か」と対象・条件 → 必要なら比べられない旨。
- 良い例（A1、リンク・237）: 「夜2回以上トイレに起きる男性、27.1%。\n日本排尿機能学会の委員会による2023年の全国調査（オンライン、20〜99歳）の数字で、40歳以上では31.4%。調査ごとに数え方が違い、数字どうしは比べられません。\n何回から相談かも記事に。」（nocturia-night-urination 209・213行）
- 良い例（A2、リンク・223）: 「1日の平均睡眠が6時間未満の男性、37.5%。\n厚労省の睡眠ガイド2023が引く、令和元年の国民健康・栄養調査の数字です。…」（sleep-support 71・80行）
- 向く記事: 全国調査・有病率・基準値のある記事（nocturia、sleep-support、hair-scalp-care、winter-vitamin-d）。
- 注意: 不安をあおる数字の出し方をしない（「〜人に1人が危ない」等）。数字の対象（男性・年齢・調査方法）を落とさない。

### B 誤解→正解（版1 型5 の「誤解をほどく」部分を統合）
- 1行目の形: よく聞く言い方を「」か「〜という話」で名指しする。答えは2行目。
- 構成: 誤解の名指し → 資料の言葉で正す（主体を付ける）→ 留保。
- 良い例（B1、リンク・253 ※250 超。予約前に短くする）: 「「カフェインは1日400mgまで」は、日本の食品の基準？\n食品の安全の面では、一日摂取許容量も摂取量の目安も、国として設定されていません。睡眠の面では、厚労省の睡眠ガイド2023が…「400mgを超えないように」と書いています。」（caffeine-limits 108行）
- 良い例（B2、fact・229）: 「夜中のトイレの回数、思い出して数えた回数と、記録した回数。\n夜間頻尿診療ガイドラインは、両者は必ずしも一致せず、特に高齢者では思い起こした回数のほうが多い傾向がある、としています。…」（nocturia-night-urination 87行）
- 向く記事: 記事に「よくある誤解」「〜と紹介されることがある」と書いてある記事（nocturia の寝る前の水、blue-light の6団体の意見書、hair-damage-care の「補修」）。
- 注意: **他人の投稿・個人を名指ししない**。扱うのは記事に書いた「よくある言い方」だけ。資料がはっきり否定していることは主体を付けて短く言ってよい（「〜学会は科学的根拠がないとしています」）。

### C 場面から入る
- 1行目の形: 誰にでもある一般的な場面を名詞止めか短い文で（「冬の朝、ひげを剃ったあとにヒリつく。」）。
- 構成: 場面 → その場面について資料が言うこと（主体付き）→ 目安・留保。
- 良い例（C1、リンク・212）: 「冬の朝、ひげを剃ったあとにヒリつく。\n米国皮膚科学会（AAD）は一般向けに、毛の流れに沿って剃ることを…大事な手順に挙げています。刃は5〜7回で交換、とも（米国の目安）。」（winter-shaving-skin 122・131行）
- 良い例（C2、リンク・233）: 「腰を痛めた翌朝。休む？ いつもどおり動く？\n腰痛診療ガイドライン2019は、急性腰痛では安静より活動性維持が有用としています（弱い推奨）。…」（desk-back-pain 92・93行）
- 向く記事: 生活の場面がはっきりした記事（winter-shaving-skin、desk-back-pain、blue-light-glasses、glp1-diet の「SNS・広告で見かける」）。
- 注意: **体験談にしない。「私」「当サイトの運営者が」を使わない**（D0017）。場面に不安をあおる言葉を足さない。

### D 用語の言い換え・言葉の正体（版1 型5 の「言葉の出どころ」部分を統合）
- 1行目の形: 「用語」＝短い言い換え。または「〜」は誰の言葉か。
- 構成: 言い換え → その用語が出てくる資料の事実 → 誤解しやすい点。
- 良い例（D1、リンク・228）: 「「専ら医薬品」＝食品には使えない、医薬品の成分。\nメラトニンは厚労省のこのリストに載っているため、日本ではサプリ（食品）として売れません。「禁止された成分」とは少し意味が違います。…」（melatonin-japan-vs-us 84・94行）
- 良い例（D2、リンク・226）: 「「睡眠休養感」＝眠って休めた、という感覚。\n厚労省の睡眠ガイド2023は…」（sleep-support 63・89行）
- 良い例（版1 型5）: 「『加齢臭』『ミドル脂臭』は、医学の病名ではありません。／『ミドル脂臭』は企業が名付けた呼び名、…」（body-odor-sweat 90・95行）
- 向く記事: 制度・区分の言葉（専ら医薬品、要指導医薬品、医薬部外品）、検査値（クレアチニン）、企業が作った呼び名がある記事。
- 注意: 定義は記事にある定義・説明だけ。当社の言い換えが資料の定義より広くならないように。

### E 短い箇条（版1 型6 を統合）
- 1行目の形: 「〜から3つ」「〜で確かめる3つ」のように、当社が抜き出したと分かる言い方。
- 構成: 1行目 → 行頭「・」で**3行まで** → 必要なら留保を1行。
- 良い例（E1、リンク・201）: 「口のケア、日本・英国・米国の資料に共通して出てくるのは3つ。\n・歯磨き\n・歯間清掃（フロスなど）\n・歯科の定期健診\n舌の清掃と洗口液は、資料で見解が分かれます（順位ではありません）。」（oral-care-basics 93行）
- 良い例（E2、fact・160）: 「自宅の筋トレ、厚労省のガイド2023に書かれた目安から3つ。\n・無理せず「できなくなるところまで」\n・血圧の急な上昇を抑えるため、息をこらえない\n・筋肉を休める日をとる」（strength-training-guide 187〜189行）
- 向く記事: 手順・確認点が列挙されている記事（strength-training-guide、oral-care-basics、hair-tonic-review の「区分・期間・使い方・受診の目安」）。
- 注意: 「資料が示すのは3つ」と資料の中身を N 個に限る言い方はしない（style-guide 8章）。記事が「共通するのは3つ」と書いている場合か、「〜から3つ」と当社が抜き出したと分かる場合だけ。「〜3選」「最大化」は NG。

### F 時系列・順番
- 1行目の形: 時刻・年月日・数量の流れを1文で（「朝9時に400mgを摂ると、19時にも100mg相当が残る」）。
- 構成: 流れ → それが誰の例・計算か → 個人差・条件。
- 良い例（F1、リンク・212）: 「朝9時に400mgを一度に摂ると、夜7時にも100mg相当が残る（半減期5時間の場合）。\n厚労省の睡眠ガイド2023が挙げている計算の例です。日本人の血中半減期は3〜7時間とばらつきがある、とも書いています。」（caffeine-limits 191行）
- 良い例（F2、リンク・254 ※250 超。予約前に短くする）: 「2023年6月26日、厚労省のワーキンググループがメラトニンを再審議。\n結論は、引き続き医薬品の成分としての扱いでした。…」（melatonin-japan-vs-us 94〜96・125行）
- 向く記事: 時刻・期間・制度の経緯がある記事（caffeine-limits、melatonin、ed-otc-tadalafil の承認と販売の日付、glp1-diet の効能変更）。
- 注意: 条件（「半減期5時間の場合」等）を1行目か2行目に必ず置く。

### G 国・区分による違い（版1 型2「意外な事実・ねじれ」を統合）
- 1行目の形: 「〜、日米で区分が違います。」「〜、日本と WHO・米国でほぼそろっています。」
- 構成: 1行目 → 国（区分）ごとに1行（「米国：」「日本：」）→ 留保。
- 良い例（G1、リンク・221）: 「歯を漂白する薬剤の扱い、日米で違います。\n日本：…\n米国：…」（whitening-japan-vs-overseas 70・71行）
- 良い例（G2、リンク・192）: 「フケ用の「ケトコナゾール」、日米で区分が違います。\n米国：1%シャンプーはFDAが承認した市販薬（2%は処方薬）。\n日本：外用剤は医療用医薬品。\n当サイトは個人輸入を勧めません。」（dandruff-shampoo 89・95・169行）
- 向く記事: 「日本と海外」の記事（retinoids、melatonin、ashwagandha、whitening、dandruff、strength-training-guide、loh-testosterone の基準値）。
- 注意: どちらが良いとは言わない。**海外で買えるものには個人輸入の注意を添える**（4章）。

### H 【見出し】
- 1行目の形: 【】で囲んだ短い見出しだけ（全角15字ほどまで）。#PR があるときは「#PR 【…】」。
- 構成: 見出し → 具体的な目安・数字・行動（主体付き）→ 記事URL。公的機関の告知の形。
- 良い例（H1、リンク・212）: 「【冬の乾燥とひげ剃り】\n東京の1・2月の平均湿度は、7月より約25ポイント低い（気象庁の平年値）。日本皮膚科学会の手引きは、外気の乾燥や室内暖房による低湿度を、皮膚が乾燥する要因に挙げています。」（winter-shaving-skin 72行）
- 向く記事: 公的機関の目安・注意喚起がある記事（blue-light-glasses の作業の目安、beard-hair-removal の国民生活センター、季節もの）。
- 注意: 【】は1行目だけ。**見出しに「注意」「警告」「危険」「⚠」を入れない**。7日間で2件まで（3章）。

### I Q&A
- 1行目の形: 「Q. 〜？」。2行目「A. 〜」。
- 構成: Q と A を1つずつ。A に主体を付ける。後日、同じ記事のリンク告知を出す場合は、その告知で「つづき」と書いてよい（任意。同じ記事の間隔の規則〈3章〉と両立させる）。
- 良い例（I1、fact・136）: 「Q. 汗そのものは、におう？\nA. MSDマニュアル家庭版（企業が発行する医学事典）によると、どちらの汗腺の汗も、分解される前は悪臭を生じません。」（body-odor-sweat 79・249・272行）
- 良い例（I2、リンク・214。I1 のつづき）: 「「ミドル脂臭」は誰の言葉？\n企業（マンダム）が2013年に名付けた呼び名です。…\n昨日の「汗はにおう？」のつづきも記事に。」（body-odor-sweat 90・95行）
- 向く記事: 答えが一言で言える記事。fact 投稿に向く。
- 注意: 1行目が「？」で終わるので、疑問形の上限（3章）に数える。

### J 相談の目安・チェックリスト（版1 型8 を統合）
- 1行目の形: 「次の〜があれば、〜へ（機関名）。」または「〜な方へ。」（版1 型8 の形）。
- 構成: 1行目に誰の目安か → 行頭「□」で3〜5行 → 記事URL。
- 良い例（J1、リンク・181）: 「腰痛でこれがあれば、すみやかに整形外科へ（日本整形外科学会）。\n□安静にしても痛みが軽くならない\n□しだいに悪化する\n□発熱\n□脚のしびれ・力が入らない\n□尿漏れ」（desk-back-pain 72〜78行）
- 良い例（J2、リンク・208）: 「ミノキシジル5％外用、6カ月たつ前でも中止して相談する場合（添付文書）。\n□脱毛状態の悪化\n…」（hair-tonic-review 101・115行。商品名・リンクを同じ投稿に置かない。リンクを足す案件では再審査）
- 向く記事: 受診・相談の目安の節がある記事（desk-back-pain、nocturia、dandruff、blue-light、loh-testosterone）。
- 注意: 受診・相談の目安だけ。**不安をあおる前置きを付けない**（「放っておくと…」）。項目は資料の言葉のまま。

### K 対象者の数字
- 1行目の形: 「「〜」と考えている〇〇、〇%。」（主観の回答の数字）。
- 構成: 数字 → 調査の主体・年・方法 → 「回答は主観で診断ではない」などの注記。
- 良い例（K1、リンク・223）: 「「更年期障害の可能性がある」と考えている50代男性、14.3%。\n厚労省の2022年のネット調査で、医療機関で診断されたと答えたのは1.7%でした（回答は本人の主観で、診断ではない、との注記つき）。\n検査は何科かも。」（loh-testosterone 91・93・94・97行）
- 向く記事: 意識調査の数字がある記事。
- 注意: 主観の回答である注記を落とさない。uro・男性の健康の話題（D0018）の投稿と同じ週に重ねない。

### M お金・契約の確認点（版1 型7）
- 1行目の形: 「広告で『〜』を見たら、〜を確認。」
- 構成: 確認点 → 法令・公的機関の根拠 → 例外。
- 良い例（版1）: 「ヒゲ脱毛の広告で『月々○円』を見たら、総額・支払回数・分割手数料を確認。／1か月超・5万円超の脱毛のコース契約は、医療機関でもエステでも特定商取引法の対象で、クーリング・オフや中途解約のルールがあります（都度払いは原則対象外）。」（beard-hair-removal 183・225行）
- 向く記事: 契約・費用の節がある記事（beard-hair-removal、aga-selfcare-vs-clinic、strength-training-guide のパーソナルジム）。
- 注意: クリニック系の記事では、クリニック名・料金・「無料カウンセリング」を書かない（checklist 4章）。

### Q 疑問から入る（版1 型1）
- 1行目の形: 読者が実際に持つ疑問をそのまま（「〜？」）。
- 構成: 疑問 → 答えの一部を誰が言ったか付きで。
- 良い例（版1）: 「舌磨き、毎日したほうがいい？／日本の公的機関と英国NHSは勧め、米国歯科医師会は『必須の手順ではない』としています。」（oral-care-basics）
- 向く記事: どれでも。ただし**疑問形の上限（3章）**があるので、ほかの型で書けないときに使う。
- 注意: 効能を問う疑問形・釣りの問いは NG（4章）。

### V 見解が分かれるところを並べる（版1 型4）
- 1行目の形: 「〜、機関によって言い方が違います。」など（疑問形にしない書き方を優先）。
- 構成: 機関ごとに分けて1文ずつ。どちらが正しいとは言わない。機関は2つまでが目安。
- 良い例（版1。1行目は疑問形）: 「冬はビタミンDが足りなくなる？／英国NHSは、秋冬にサプリを毎日とることを『検討』するよう勧めています。日本の食事摂取基準は、食事と適度な日光浴が基本です。」（winter-vitamin-d）
- 向く記事: 機関の比較表がある記事（creatine、caffeine-limits、oral-care-basics、winter-vitamin-d）。

### 使わない型
- **L スレッド2連（本体＋返信に URL）**: 使わない。理由は 01 異議4: (a) X の製品責任者が「リンクは減点していない」「返信に置く必要はもうない」と投稿（2026-04・07）。(b) 公開コードの `OONRetweetReplyFilter` で、フォロー外の人には返信が届きにくい。(c) 費用が $0.200 → $0.215／回。(d) 開発者ガイドラインの「AI 生成の返信」の事前承認に、自分の投稿への返信が当たるか読み切れない。→ URL なしの fact 投稿を型の実験場にする。
- **キャラクター口調の定型・流行の定型**（同じ日に複数の医師が使う型など）: 使わない（4章）。
- **「私が選ぶ〜はこれ一択」**: 使わない（体験・推奨・最大級）。

## 3. ローテーション規則

判定は、リンク投稿と fact 投稿をまとめた**投稿順**（日付順。同じ日は fact が先、リンクが後。`x_post.py` の並べ方と同じ）で行う。予約の時点で、すでに投稿済みの直近の投稿も含めて数える。

| # | 規則 | 数え方 |
|---|---|---|
| R1 | **同じ型を2連続で使わない** | `"type"` の ID で比べる |
| R2 | **1行目が「？」で終わる投稿は、直近5件のうち2件まで** | 1行目の末尾（#PR を除く）が「？」。型I・型Q は必ず数える。型C の1行目に「？」が入る場合も末尾が「？」なら数える |
| R3 | **「〜も。」で終わる行がある投稿は、直近3件のうち1件まで** | どの行でも、行末が「も。」なら数える（「〜も記事に。」は数えない） |
| R4 | **同じ記事を根拠にする投稿は、7日以上あける** | リンク・fact をまたいで数える。日付の差が7日以上 |
| R5 | **1行目の書き出しの文字種・記号を2連続させない** | 書き出しの1字（#PR を除く）を次の区分で比べる: 数字／「／【／英字（Q. を含む）／カタカナ／ひらがな／漢字 |
| R6 | **【見出し】（型H）は7日間で2件まで** | 公的機関の真似に見えないように |
| R7 | 1行目の文面が過去の投稿と同じにならない | X の重複拒否・単調さ |

- R1・R2 は `scripts/x_post.py` の `rotation_warnings` が警告を出す（`--check` で失敗にできる）。R3〜R7 は目視（経営企画が x_post.py に足す場合の仕様は上の「数え方」）。
- **予定の日付・記事を変えられない既存の予約で R4 を満たせない場合**は、異なる事実・異なる型を使い、03 の表に例外として記録する（0053 では3組。今後の予約では日付の段階で避ける）。
- 型の割り当ての目安: リンク告知は A・D・G・H・J・M（公的機関の形：見出し・数字・行動・URL）、fact は B・C・E・I（URL なしで言い切れる一点）。Q と V は R2 の上限内で。

## 4. 全部の型に共通の NG

版1から引き継ぐもの:
- 効能・効果の言い切り（「効く」「治る」「改善」「生える」）、安全の保証（「副作用なし」）、最大級（「最強」「No.1」）、ランキング（checklist 1・2章）
- 体験談・口コミの形（「使ってみたら」「◯週間で」）。運営者の使用の事実と購入リンクを結びつける言い方（checklist 1章、0029）
- 恐怖・不安をあおる言葉（「手遅れ」「ヤバい」「知らないと損」）
- クリニック系の記事で、クリニック名・料金・「無料カウンセリング」等（checklist 4章）
- 医療用医薬品の製品名（一般名のみ）。GLP-1 の痩身目的の医療機関・オンライン診療への誘導（D0015）
- 記事に無い事実・数字。記事の留保（主体・対象・条件・確実性）を落とした要約（style-guide 7章）
- 「医師監修」「専門家推薦」など、事実で無い権威づけ
- 釣りの問い（答えが記事にない問い、記事の結論と逆を匂わせる問い）
- 話題のハッシュタグ・無関係なハッシュタグ、他人への @メンション（X の開発者ガイドライン）
- 効能・効果を問う疑問形（「〜で治る？」「〜に効く？」「ぐっすり眠れる？」）、焦り・不安をあおる疑問形（「まだ〜してないの？」）
- 自称は「当サイト」。「私」は使わない（D0017）
- 性の悩みの記事の告知は、医学用語のみ（例: 「ED（勃起不全）」）・#PR なし・要指導医薬品の販売名を書かない・購入や受診先への誘導をしない（D0018）
- 海外で買えるもの（海外のサプリ・市販薬など）を扱う告知は、個人輸入の注意を添える

版2で追加（01 申し送り4）:
- **流行している口調・定型に乗らない**（同じ日に複数のアカウントが使うキャラクター口調の型など）。
- **「私が選ぶ」「一択」「〜で分かったこと（体験）」の形**（体験談・推奨・最大級）。
- **「（医師監修）」等の権威づけ**を、事実でない限り付けない（反応の多い投稿にも見られたが、当社は使わない）。
- **他人の投稿・個人を名指しして正す形**（「〜という投稿を見かけたが」）。型B は記事に書いた「よくある言い方」だけを扱う。
- **【見出し】に「注意」「警告」「危険」「⚠」を入れる形**（公的機関には適切でも、当社が使うと不安をあおる印象になる）。
- 絵文字・⚠・❌・✔・👇 などの記号（1章で使ってよい記号以外）。

## 5. 投稿前のチェックリスト

- [ ] `"type"` に2章の ID がある。1行目がその型の形になっている
- [ ] ローテーション規則 R1〜R7（3章）を満たす（直近の投稿済みの分も含めて数えた）。満たせない既存の予約は 03 に例外として記録した
- [ ] 本文の事実・数字が、すべて記事の現在の本文にある（記事を開いて確かめた）
- [ ] 数字・見解のそばに「誰が言ったか」がある。機関名は2つまでが目安。見解の違う機関を1つの主語にまとめていない
- [ ] 対象・条件・確実性（「成人」「健康な人など」「確実性は低い」「主観の回答」等）を落としていない
- [ ] 効能・断定・最大級・体験談・恐怖訴求・ランキングが無い。4章の追加の NG も無い
- [ ] クリニック系の記事なら、クリニック名・料金・カウンセリングが無い
- [ ] アフィリエイトリンクが描画される記事・ページなら #PR があり、1行目の先頭にある（`python3 scripts/x_post.py --date <日付> --dry-run` と目視）
- [ ] リンクを描画しない記事の告知に #PR が無い
- [ ] リンク投稿は記事URLが最後の行に1つ。fact 投稿は URL なし。重み付き 250 以内を目安（280 は上限）
- [ ] 「整理しました」で終わっていない
- [ ] 過去に投稿した文面と同じでない（X の重複拒否）

## 6. queue の JSON

```json
{"date": "2026-11-06", "article": "articles/nocturia-night-urination.html", "type": "A", "text": "…\nhttps://hclab16k.github.io/health-affiliate-site/articles/nocturia-night-urination.html"}
{"date": "2026-11-05", "kind": "fact", "article": "articles/body-odor-sweat.html", "type": "I", "text": "…"}
```

- **`"type"` は必須**（2026-10-30 以降の投稿）。値は2章の ID（A・B・C・D・E・F・G・H・I・J・K・M・Q・V）の1つ。L は使わない。
- `x_post.py` は `"type"` の無い 2026-10-30 以降の投稿に警告を出す。投稿は止めない（`--check` では失敗）。
- 型ごとの効果を後で集計するために使う（7章）。

## 7. いまは使わないもの（理由）

- **URL を返信に置く形・スレッド**: 2章「使わない型」L のとおり。
- **画像の添付**: x_post.py は画像を送らない。記事の OGP カードが画像の役。全記事が同じ `images/og.png` のため、カードの見た目が毎回同じ（記事ごとの OGP 画像は別案件）。01 では公的機関・報道の上位13件のうち11件が画像付きだったため、優先度は高い。
- **他人の投稿の引用**: API の引用は 2026-04 にセルフサービスの API から削除（01 B）。
- **絵文字・ハッシュタグ（#PR 以外）**: 1章のとおり。

## 8. 測り方

- GA4 の流入元（t.co / x.com）を週ごとに見る。版2の型の投稿（2026-10-30〜）と、版1の投稿（10/14〜10/29、ほぼ型Q）を比べる。
- X API の Owned Reads（自分の投稿の読み取り、$0.001／件）で、投稿後30日以内なら URL のクリック数（`url_link_clicks`）とインプレッションが取れる。queue の `"type"` と突き合わせて型ごとに集計する。スクリプトの追加と支出はオーナー確認（D0023 3項）。
- 件数が少ないうちは傾向を見るだけにし、結論を急がない。同じ週に型を1つだけ変える比較を優先する。
