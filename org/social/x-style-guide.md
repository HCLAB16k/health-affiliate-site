- 版: 1（0045 レビュー済み）。2026-10-13 リサーチ部作成、0045 レビュー（`org/pipeline/0045-x-post-improvement/05-review.md`）の指摘 S1〜S9 を反映。
- 根拠: `org/pipeline/0045-x-post-improvement/01-research.md`
- 上位のルール: `org/compliance-checklist.md` 3章・4章（D0010）、`org/style-guide.md` 7章、`org/social/README.md`。本書と食い違ったら上位のルールが優先。

## 0. 考え方（ひとことで）

**記事の「要約」ではなく、読者の「疑問」から書き始める。答えの一部（事実1つと、誰が言ったか）を本文で見せ、残りを記事で読んでもらう。**

- 今の告知は「〜を、〇〇の資料で整理しました」で終わる要約の形がほとんど（10/14 以降の23件すべて）。どの記事も同じ印象になり、1行目で止まる理由がない。
- 一方で、反応を増やす要因として研究で挙がる「恐怖の言葉」（Lohmann 2018）や、誤情報のほうが広がりやすいという報告（厚労科研 2023）は、当社は使えない・使わない。**中立のまま「問い」と「意外な事実」で止まってもらう**のが当社の型。

## 1. 基本の形

```
（#PR ）1行目: 読者の疑問、または意外な事実・違い（全角 15〜30 字ほど）
2行目: 答えの一部。事実1〜2つ ＋（誰が言ったか）
3行目: 記事で分かることを「〜も。」で短く（省略可）
4行目: 記事URL（単独の行）
```

| 項目 | 目安 | 理由・出典 |
|---|---|---|
| 1行目 | 疑問形（「〜？」）か、意外な事実・違い。全角30字以内 | 当社の今の文は1文目が平均35字前後で、資料名から始まるものが多い。X 公式の一般向けの助言（簡潔に）は二次情報経由（01 参照） |
| 本文の長さ | 全角 90〜120 字（URL 除く）。重み付きで 200〜270 | 短すぎると答えを見せられない（Lohmann 2018 は長めの文が RT と関連）。上限は x_post.py の 280 |
| 改行 | 2〜3か所。ブロックの間に1つずつ。空行は入れない | 1行目を独立させる。改行は重み1 |
| 機関名・資料名 | 1投稿に **2つまでが目安**。1行目の問いに答えるのに要る機関（見解が分かれる点を並べる場合など）は3つ以上でもよい。それ以外は記事に回す。複数の機関を1つの主語にまとめてよいのは、まとめた機関の見解が同じ点（例: 3か国とも成人の上限は1日100µg）だけ。見解が違う点は、機関ごとに分けて書くか記事に回す（checklist 6章・style-guide 4章） | 今の文は機関名が多く、何の話かが後ろに回る |
| 数字 | 1投稿に1〜2個。数字のそばに出典 | 記事にある数字だけ。単位・対象（成人など）を落とさない（style-guide 7章） |
| URL | 本文の最後の行に1つ（記事URL） | x_post.py の要件。返信に置く形は当面使わない（5章） |
| #PR | アフィリエイトリンクが描画される記事・ページの告知は、1行目の先頭に「#PR」（0045 レビューで確定）。描画されない記事には付けない（D0010。A8 の自動置換を ON にしたときは見直す） | 消費者庁の運用基準は「視認しにくい表示の末尾の位置」を不明瞭な例に挙げる（第3の1⑵オ）。文頭の「PR」は明瞭な表示の例（2⑴ア） |
| ハッシュタグ | #PR 以外は付けない | 話題のタグに乗せるのは X の開発者ガイドラインで禁止（トレンド操作）。中立の印象を保つ |
| 絵文字 | 使わない | 煽りの印象を避ける。絵文字は重み2 |
| 文末 | 「整理しました」で終えない。「〜も。」など。「〜とされています。」は、同じ文か直前の文で機関名が分かるときだけ使う | 要約の型から抜ける。誰の見解かを読めるようにする（style-guide 4章） |

## 2. 使える型（当社の制約の中で）

各型に「良い例（当社の記事で作った案）」と「NG 例（規制・当社ルール上ダメな型）」を付ける。良い例はすべて記事の本文にある事実だけで作った（01 の書き直し案の表を参照）。

### 型1: 疑問から入る（Q→A の一部）
- 1行目に、読者が実際に持つ疑問をそのまま置く（知恵袋や記事の導入にある言い方）。2行目で答えの一部を、誰が言ったか付きで示す。
- 良い例: 「舌磨き、毎日したほうがいい？／日本の公的機関と英国NHSは勧め、米国歯科医師会は『必須の手順ではない』としています。」
- NG 例: 「まだ舌磨きしてないの？ 口臭、周りは気づいてます」（恐怖訴求・煽り）

### 型2: 意外な事実・ねじれ（「Aなのに、Bでは〜」）
- 国や区分で扱いが違うこと、よく聞く話の前提が違うことを1行目に。
- 良い例: 「米国ではサプリとして売られているメラトニン。日本のドラッグストアで見かけないのはなぜ？／日本では厚労省の『専ら医薬品』リストに載る成分で、健康食品としては売れません。／2023年の判断の理由、時差ぼけへの評価の違い、個人輸入の注意も。」
- NG 例: 「日本では買えない、海外で話題の睡眠サプリ」（個人輸入を誘う。効能の暗示）

### 型3: 数字を1つだけ見せる
- 記事の数字のうち、読者の思い込みとずれるもの・自分ごとにしやすいものを1つ。出典を数字のそばに。
- 良い例: 「筋トレは週何回・1回何分？／成人の目安は、厚労省のガイド2023が週2〜3日、WHO・米国が週2日以上。一方、筋トレの時間の推奨値は、3機関とも示していません。」
- NG 例: 「1日10分で体が変わる筋トレ」（効果の断定。記事に無い数字）

### 型4: 見解が分かれるところを並べる（A vs B）
- 機関ごとに言い方が違う点を、どちらが正しいとは言わずに並べる。機関は2つまでが目安（1章）。機関ごとに分けて書く。
- 良い例: 「冬はビタミンDが足りなくなる？／英国NHSは、秋冬にサプリを毎日とることを『検討』するよう勧めています。日本の食事摂取基準は、食事と適度な日光浴が基本です。」
- NG 例: 「日本の基準は甘い。冬はサプリが必須」（断定・一方の否定・サプリの効能の暗示）

### 型5: よく聞く言葉の正体（誤解をほどく）
- 広告やSNSでよく見る言葉の定義・出どころを1行目に。
- 良い例: 「『加齢臭』『ミドル脂臭』は、医学の病名ではありません。／『ミドル脂臭』は企業が名付けた呼び名、『加齢臭』は原因物質の説明が企業の研究発表がもとです。『何歳から』も資料によって40歳以上・50歳代以降と違います。」／「トリートメントの『補修』は、どういう意味？／元の状態に戻すことではなく、効果は使っている間に限られます（日本化粧品工業会のガイドライン）。」
- NG 例: 「加齢臭はこれで消える」「傷んだ髪が元通りに」（化粧品・医薬部外品の効能の範囲を超える。checklist 1章）

### 型6: 確かめる順番（短い箇条）
- 迷ったときに確かめる項目を、3〜4個の名詞で並べる（「区分・期間・使い方・受診の目安」）。行頭の「・」を使う場合も3行まで。
- 良い例: 「育毛剤、何か月で見直す？／医薬品のミノキシジル5％外用は、添付文書に『少なくとも4カ月』使い、6カ月で改善がなければ中止して相談、とあります。…区分・期間・使い方・受診の目安の順に。」
- NG 例: 「育毛剤の効果を最大化する使い方3選」（最大級・効能の暗示・ランキング風）

### 型7: お金・契約の確認点
- 広告の言い方（「月々○円」など）を見たときに何を確かめるか。公的機関の注意喚起にもとづく。
- 良い例: 「ヒゲ脱毛の広告で『月々○円』を見たら、総額・支払回数・分割手数料を確認。／1か月超・5万円超の脱毛のコース契約は、医療機関でもエステでも特定商取引法の対象で、クーリング・オフや中途解約のルールがあります（都度払いは原則対象外）。」
- NG 例: 「〇〇クリニックなら月々3,000円、今なら無料カウンセリング」（クリニック名・料金。医療広告の限定解除の要件①を満たさない。checklist 4章）

### 型8: 相談の目安（受診のサイン）
- 「どうなったら相談するか」を、資料の言葉で1つ示す。怖がらせない。
- 良い例: 「冬、ひげ剃りのあとのヒリつきが気になる方へ。…剃り方、赤いブツブツの見分け方、皮膚科に相談する目安も。」
- NG 例: 「そのブツブツ、放っておくと大変なことに」（恐怖訴求）、「医師も勧める剃り方」（推薦を装う）

## 3. 全部の型に共通の NG

- 効能・効果の言い切り（「効く」「治る」「改善」「生える」）、安全の保証（「副作用なし」）、最大級（「最強」「No.1」）、ランキング（checklist 1・2章）
- 体験談・口コミの形（「使ってみたら」「◯週間で」）。運営者の使用の事実と購入リンクを結びつける言い方（checklist 1章、0029）
- 恐怖・不安をあおる言葉（「手遅れ」「ヤバい」「知らないと損」）
- クリニック系の記事で、クリニック名・料金・「無料カウンセリング」等（checklist 4章）
- 医療用医薬品の製品名（一般名のみ）
- 記事に無い事実・数字。記事の留保（対象・条件・確実性）を落とした要約（style-guide 7章）
- 「医師監修」「専門家推薦」など、事実で無い権威づけ
- 釣りの問い（答えが記事にない問い、記事の結論と逆を匂わせる問い）
- 話題のハッシュタグ・無関係なハッシュタグ、他人への @メンション（X の開発者ガイドライン）
- 効能・効果を問う疑問形（「〜で治る？」「〜に効く？」「ぐっすり眠れる？」）、焦り・不安をあおる疑問形（「まだ〜してないの？」）（style-guide 3章と同じ線）
- 自称は「当サイト」。「私」は使わない（D0017）
- 性の悩みの記事の告知は、医学用語のみ（例: 「ED（勃起不全）」）・#PR なし・要指導医薬品の販売名を書かない（D0018）
- 海外で買えるもの（海外のサプリ・市販薬など）を扱う告知は、個人輸入の注意を添える

## 4. 投稿前のチェックリスト

- [ ] 1行目が「疑問」か「意外な事実・違い」になっている（資料名や「〜の記事を書きました」から始まっていない）
- [ ] 本文の事実・数字が、すべて記事の現在の本文にある（記事を開いて確かめた）
- [ ] 数字・見解のそばに「誰が言ったか」がある。機関名は2つまでが目安（3つ以上なら1行目の答えに要るか確かめる）。見解の違う機関を1つの主語にまとめていない
- [ ] 対象・条件・確実性（「成人」「健康な人など」「確実性は低い」等）を落としていない
- [ ] 効能・断定・最大級・体験談・恐怖訴求・ランキングが無い
- [ ] クリニック系の記事なら、クリニック名・料金・カウンセリングが無い
- [ ] アフィリエイトリンクが描画される記事・ページなら #PR がある（`python3 scripts/x_post.py --date <日付> --dry-run` で確認）
- [ ] #PR が1行目の先頭にある（目視。dry-run は #PR の有無しか見ない）
- [ ] リンクを描画しない記事の告知に #PR が無い
- [ ] 記事URLが最後の行に1つ。重み付き 280 以内（同上の dry-run で確認）
- [ ] 「整理しました」で終わっていない
- [ ] 過去に投稿した文面と同じでない（X の重複拒否）

## 5. いまは使わないもの（理由）

- **URL を返信に置く形・スレッド**: リンクの「減点」は X の製品責任者が否定しており（2025-10-19）、届きにくいという話の根拠は二次情報（Buffer・Nieman Lab）のみ。返信の投稿にも URL を入れると $0.20 かかり、本体の $0.015 と合わせて費用は増える。x_post.py は1件の投稿しか作れず、本文に記事URLを求める。X の開発者ガイドラインの自動返信の条件（相手が先に関わった場合のみ）が自分の投稿への返信に当たるかも未確認。→ 効果を自社の数字で確かめてから、経営企画が判断する。
- **画像の添付**: x_post.py は画像を送らない。記事の OGP カード（`summary_large_image`）が画像の役を果たしているが、全記事が同じ `images/og.png` のため、カードの見た目が毎回同じ。記事ごとの OGP 画像は別案件で検討（01 の申し送り）。
- **絵文字・ハッシュタグ（#PR 以外）**: 1章のとおり。

## 6. 測り方（案）

- GA4 の流入元（t.co / x.com）を週ごとに見る。今は X からの流入の基準値が無いので、10/14 以降の新しい型の投稿と、10/13 までの要約型の投稿を比べる。
- X API の Owned Reads（自分の投稿の読み取り、$0.001／件）で、投稿後30日以内なら URL のクリック数（`url_link_clicks`）とインプレッションが取れる（docs.x.com）。スクリプトの追加と支出はオーナー判断。
- 型の比較は、同じ週に型を1つだけ変えて行う（例: 1行目が疑問の投稿と、意外な事実の投稿）。件数が少ないうちは傾向を見るだけにし、結論を急がない。
