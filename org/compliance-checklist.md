# コンプライアンス・チェックリスト（全部署共通・レビュー部の審査基準）

迷ったら「言わない」側に倒す。本書は実務上の目安であり法的助言ではない。判断に迷う表現は
オーナー経由で広告主・ASPに確認する。

## 1. 薬機法（医薬品医療機器等法）・医薬品等適正広告基準

### 商品区分ごとに言える範囲が違う（最初に区分を確認する）
| 区分 | 言える範囲 | 例 |
|---|---|---|
| 医薬品 | 承認された効能効果 | 発毛剤（ミノキシジル配合の第1類医薬品）等 |
| 医薬部外品 | 承認された効能効果の範囲内 | 育毛剤「育毛、薄毛、脱毛の予防、発毛促進、ふけ、かゆみ」等 |
| 化粧品 | 化粧品の効能効果の範囲（56項目）内 | 「肌を整える」「肌にうるおいを与える」「乾燥による小ジワを目立たなくする」（効能評価試験済みの場合のみ） |
| 機能性表示食品 | 届出された表示の範囲内のみ | 届出番号・届出表示を確認して引用 |
| 一般の健康食品・サプリ | **効能効果は一切言えない** | 成分の一般的な説明・「〜を意識する方に」程度 |

### NG表現（例）
- 疾病の治療・予防: 「AGAが治る」「薄毛が改善」「不眠に効く」「疲労回復に効果」（サプリの場合）
- 断定・保証: 「必ず生える」「確実に」「効果を保証」「シワが消える」
- 安全性の保証: 「副作用なし」「安全」「100%天然だから安心」
- 医師・専門家の推薦を装う: 「医師も推薦」「〇〇大学が認めた」（根拠と許諾が無いもの）
- 最大級・比較: 「最強」「最も効く」「他社より効果が高い」
- 身体の組織機能の増強: 「代謝アップ」「免疫力を高める」（サプリの場合）
- 使用前後の比較写真で効果を示す（医薬品等適正広告基準で原則NG）

### OK表現（例）
- 「〇〇が配合されています」「メーカー公式サイトによると〜」（出典付き）
- 「〇〇を意識する方に選ばれています」
- 医薬部外品・機能性表示食品は、承認/届出の文言をそのまま引用し、その範囲を超えない

## 2. 景品表示法

- 優良誤認: 根拠の無い「No.1」「満足度◯%」「効果◯倍」。No.1 等は調査主体・時期・対象を明記できる場合のみ。
- 有利誤認: 「今だけ」「最安値」「実質無料」の根拠なし表示。定期購入の総額・解約条件を隠さない。
- ランキング・比較表: 評価基準を明記する。報酬の高さで順位を決めない。数値には出典と確認日。

## 3. ステルスマーケティング規制（景表法 告示・2023年10月施行）

- 広告を含むページは冒頭に明確な表示（既存の `pr-badge`「PR / 本記事はアフィリエイト広告を含みます」）。
- SNS投稿・note等でもアフィリエイトリンクを含むなら「#PR」「広告」を明示。
- 広告主から提供を受けた商品のレビューは、提供を受けた事実を明記。

## 4. 医療広告ガイドライン（医療法）— クリニック案件（AGA・脱毛・医療ダイエット等）

アフィリエイトサイトでも、特定のクリニックへ誘引する記事は医療広告として規制対象になりうる。
- 禁止: 虚偽、他院との比較優良、誇大、**患者の体験談**、治療前後写真（詳細説明なし）、公序良俗違反。
- 自由診療を扱う場合: 通常必要な治療内容・費用・期間・回数、主なリスク・副作用を併記する。
- 「痛みなし」「必ず効果」「業界最安」などは書かない。
- 広告主（クリニック）のレギュレーションに従う。独自に効果をうたわない。
- **該当性の判断**: 「誘引性」（患者の受診等を誘引する意図）・「特定性」（医療機関名等が特定可能。複数の医療機関を並べても満たす）・
  医業等に関する内容、の3要件で判断（医療広告ガイドライン 第2）。原文に「アフィリエイト」の語は無いが、記事風広告（広告Q&A A1-4）や
  謝礼を受けた手記の扱いから類推し、**当社のクリニック導線は医療広告として扱う**（D0003、保守的解釈）。
- **ランキング・「おすすめ◯選」で特定の医療機関を強調しない**（比較優良広告に該当しうる。出典: 広告Q&A A2-10・A1-2）。
- クリニックを掲載する記事には、掲載基準と「掲載していない医療機関より優れているという意味ではない」旨を明記する（広告Q&A A1-2）。
- 自由診療の**限定解除要件**: ①読者が自ら求めて見る情報であること ②問い合わせ先の明示 ③通常必要な治療内容・費用等
  ④主なリスク・副作用等。クリニック名を出す箇所ではこれを満たす。
- **医療用医薬品（処方薬）**: 一般向けに製品名・効能を広告しない。ガイドラインの評価を事実として紹介する場合は一般名のみとし、
  クリニックへのCTAと同じ段落に置かない。
- **ガイドラインで推奨されない治療を含むプラン**（例: AGAでのミノキシジル内服）の費用を、推奨治療と区別せずに紹介しない。
  紹介する場合はガイドライン上の評価を併記する。
- 最新の改正を確認する（2026年3月30日改正: オンライン診療受診施設に関する広告の規定新設、2026年4月1日施行）。
  出典: 厚労省「医療広告ガイドライン」・「事例解説書（第6版）」・「Q&A（令和8年版）」（mhlw.go.jp）。原文の写しは `.sources/`。

## 5. 健康増進法・特定商取引法

- 健康保持増進効果についての虚偽誇大表示をしない（健康増進法）。
- 定期購入は、総額・回数縛り・解約方法を読者に分かるよう記載する（特商法の趣旨。読者の信頼にも直結）。

## 6. 事実性・捏造防止（当社ルール）

- 体験談はオーナーの実体験（`owner-inbox` 経由の取材）か、出典のある公開情報のみ。架空の口コミを作らない。
- 医学的記述は公的機関・学会・査読論文・メーカー公式を出典にする。出典URLと確認日を残す。
- 画像を使う場合は権利を確認できるもの（オーナー撮影、広告主提供素材、ライセンス明確な素材）のみ。
